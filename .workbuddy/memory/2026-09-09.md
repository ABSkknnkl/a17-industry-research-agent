### 坑

- macOS BSD sed **不支持 `\+` 量词**，写 `[[:space:]]\+` 会静默不匹配，导致归一化失败、误判为"有差异"。改用 `[[:space:]][[:space:]]*` 或 `sed -E` 的 `[[:space:]]+`
- 判断"两文件是否同内容"不能直接用 `sort | comm`，必须先归一化 Markdown 排版（转义符、列表符号、表格对齐空格）
