三种情景

  • 基准情景：政策目标与市场化机制落地 → 独立储能/AIDC/海外需求增长 → 储能装机与出货量提升 → 行业收入增长，但价格竞争压制利润率 → 头部企业份额和盈利分化；触发条件：2026-2027年新型储能年度新增装机持续高于2025年水平 / 容量电价、现货市场和辅助服务市场规则按计划落地 / 头部企业储能出货和海外订单保持增长
  • 乐观情景：市场化机制加速 + AIDC/海外需求超预期 → 储能调用频次和资产收益提升 → 装机与出货超预期 → 价格企稳、头部企业盈利改善 → 行业集中度加速提升；触发条件：容量电价或现货市场政策提前落地并扩大覆盖范围 / AIDC储能招标和海外大储订单连续超预期 / 储能系统中标价格企稳回升，头部企业毛利率改善
  • 悲观情景：价格下行 + 收益机制滞后 → 储能项目经济性承压 → 企业盈利恶化、尾部企业退出 → 行业洗牌加速，短期收入和利润承压 → 中长期集中度提升但节奏延后；触发条件：储能系统中标价格连续下行且行业亏损面扩大 / 容量电价或现货市场政策推迟或力度低于预期 / 海外订单下滑或AIDC储能需求明显低于预期

核心风险

  • 政策风险：储能收益机制和容量电价政策落地节奏存在不确定性，可能影响储能资产经济性和装机增速
  • 产能过剩与价格竞争风险：储能系统价格持续下行，行业亏损面可能扩大，尾部企业出清压力上升
  • 技术替代风险：钠离子电池、固态电池、液流电池等新技术路线可能改变现有锂电储能竞争格局
  • 海外需求与贸易政策风险：海外储能订单、关税和电价机制变化可能影响出口型储能企业
  • 财务质量风险：行业净利润数据缺少上年同期可比口径，且部分公司储能业务占比和盈利贡献难以单独验证
