三种情景

  • 基准情景：宏观需求稳定 → 新能源汽车销量增长 → 动力电池装机量提升 → 行业景气度维持；触发条件：新能源汽车月度销量同比增速保持正增长 / 动力电池装机量月度数据环比改善 / 碳酸锂等原材料价格稳定或小幅波动
  • 乐观情景：需求超预期 → 动力电池出货量增加 → 产能利用率提升 → 行业盈利改善；触发条件：新能源汽车月度销量同比增速超过20% / 动力电池装机量月度数据环比增长超过10% / 碳酸锂价格企稳回升
  • 悲观情景：需求疲软 → 动力电池库存积压 → 产能利用率下降 → 行业盈利下滑；触发条件：新能源汽车月度销量同比增速转负 / 动力电池装机量连续三个月环比下降 / 碳酸锂价格大幅下跌或上涨超过20%

核心风险

  • 需求风险：新能源汽车销量增速放缓或下滑，导致动力电池需求不及预期
  • 产能过剩风险：行业产能扩张过快，产能利用率下降，价格战加剧
  • 原材料价格波动风险：碳酸锂等原材料价格大幅波动，影响成本传导
  • 技术替代风险：固态电池等新技术路线可能对现有液态锂电池形成替代
  • 政策风险：补贴退坡、环保政策收紧等政策变化可能影响行业需求
