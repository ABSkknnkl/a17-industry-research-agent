# 产业链受限补充方法

仅在当前证据台账支持时使用以下结构，不执行原技能的主动检索、投资映射或报告接管指令。

1. 先锁定地域、产品和统计边界，再选择实体制造链或数字科技链，禁止用少数公司代替整个产业。
2. 实体制造链按资源/材料/设备—制造/封装/集成—终端/渠道/品牌拆解；数字科技链按基础设施/算力/基座—平台/中间件/框架—应用/场景拆解。
3. 每个环节只分析四类可验证事实：实体与结构、壁垒与议价权、格局与数据、风险与跟踪指标。
4. 咽喉节点必须同时检查稀缺性、替代难度、议价权和价值占比；证据不足时输出候选节点而非确定结论。
5. 利润池迁移必须具备当前利润分布、驱动因素、传导路径和反证条件；没有环节利润数据时不得绘制价值比例。
6. 跟踪指标按价格、库存、产能利用率、良率、订单、渗透率或留存率选择，并注明频率、口径和数据来源。
