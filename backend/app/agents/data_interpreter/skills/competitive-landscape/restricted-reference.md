# 竞争格局受限补充方法

仅在当前证据台账支持时使用以下结构，不执行原技能的 PPT、界面或独立工作流指令。

1. 先确定同口径的 3—5 个行业关键指标，再比较企业；不得跨财年、币种、会计准则或统计范围直接排名。
2. 竞争者可按商业模式、客户层级、竞争姿态或产业链位置分组；分组依据必须绑定证据编号。
3. 定位表达可选二维矩阵、雷达、梯队、价值链或生态图，但坐标、评分和梯队必须来自可核验指标。
4. 公司深挖统一覆盖规模、增长、盈利、客户/产品、份额、优势、弱点和战略变化；缺失项明确标记不可得。
5. 护城河只从网络效应、转换成本、规模经济、无形资产等可验证机制判断，并检查其财务或经营表现。
6. 输出当前状态、变化方向和反证条件；不得生成买卖建议、目标价或无依据情景概率。
