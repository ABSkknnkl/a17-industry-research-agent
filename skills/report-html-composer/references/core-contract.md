# 核心交付契约

## 必须完整出现

- 第一屏：专业封面，只承担标题、研究主题、基准日、关键读数和必要披露。
- 第二屏：独立目录，完整列出 7 章 21 节并链接到正文，不与正文混排。
- 执行摘要：标题结论、核心结论、三种情景、核心风险和研究边界。
- 正文：固定 7 章、每章 3 节；章节标题与顺序不由排版模型更改。
- 文末：未解决事项、研究边界、免责声明、完整来源与证据索引。

## 事实锁

标题、段落、数字、时间、单位、结论、图表数据、证据 ID 和引用关系均视为只读。编辑模型只输出设计决策。任何未知 ID、缺失内容或越权改写都应被拒绝或降级，而不是猜测补全。

## HTML 规则

- 采用语义化 HTML、可访问导航和可检索文本；图表不是不可选中的整页图片。
- 桌面端控制舒适行长；移动端单栏；中文 `horizontal-tb`。
- 不用固定高度截断内容，不用 `overflow:hidden` 掩盖问题。
- 页面可以很长，不要求凑 A4 页数。屏幕阅读优先于打印分页。
