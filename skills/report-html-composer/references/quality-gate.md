# HTML 质量门

## 自动检查

- 7 章 21 节、封面、独立目录、执行摘要和来源索引全部存在。
- 每个小节只出现一次，构图计划与 DOM 使用同一个公开连接键。
- 计划中的 7 条章级决定和 21 条小节决定必须与 DOM 逐项一致；非压缩小节必须使用统一构图骨架，禁止退化成表格行。
- 所有正文引用都能定位到来源；所有图表都有来源；来源表可检索。
- 无水平溢出、重叠、裁切、单字窄列、强制竖排和固定高度截断。
- 图表构图满足图表数量条件；单点指标不使用伪图表。
- 桌面双栏宽度满足阈值，移动端自动单栏。
- 内容允许时至少三种正文构图，同一构图连续不超过两次。
- 来源索引必须声明并呈现材料、主体、指标、口径、可用日期、报告期、原文定位、报告引用位置、获取方式、来源层级 10 个字段。
- 页面内所有 `id` 必须唯一；克隆图表也要重新命名 SVG 标题和 marker 引用。

## 浏览器抽检

至少检查 390px、768px 和 1440px 三种宽度：目录跳转、来源跳转、来源搜索、长标题、长来源、多图网格和中文换行。浏览器检查失败时不得以“HTML 已成功生成”代替质量通过。

来源筛选不能只依赖 `hidden` 属性；如行自身 CSS 声明了 `display`，脚本必须同步控制内联 `style.display`，并验证“无匹配时为 0 行、清空后全部恢复”。

## 降级

编辑模型不可用或返回非法决策时，继续使用确定性安全编排，并在计划中标记 `decision_source=deterministic`。降级可以交付，但不能冒充模型已参与。
