# 图表型报告方向

适用于趋势、增速、波动、结构占比和对象比较占主导的报告。

- 一个关键图：`chart_focus`；图先于解释，结论必须紧邻图表。
- 两张及以上同口径图：`small_multiples` 或 `comparison_board`；只有存在真实比较关系才并排。
- 多张图需要顺序论证：`chart_sequence`；不要把整章所有图机械堆在章首或章尾。
- 多个独立单点指标：`metric_strip`；每项都显示口径和来源。
- 产业链、流程和关系：`diagram_story`，不用折线或柱形图替代关系表达。
- 图表种类由数据语义决定，不为“多样化”而错误编码。
