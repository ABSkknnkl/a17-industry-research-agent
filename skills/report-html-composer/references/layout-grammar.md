# HTML 长报告布局语法（确定性兼容层）

本文件记录旧报告和无模型降级时仍使用的布局 ID。新的编辑模型构图以 [component-grammar.md](component-grammar.md) 为准；两者同时保留是为了让历史存档继续可渲染，而不是让模型退回固定模板。

## 先选报告原型，再选小节布局

- `evidence_led`：引用密度高、来源数量多。导航、来源跳转和证据索引必须突出。
- `data_led`：图表密度高。图表先出现，正文解释口径、变化和限制。
- `narrative_led`：长篇论证为主。保持舒适行宽，用少量重点段落建立节奏。
- `balanced_research`：数据、论证和引用均衡，是默认原型。

报告原型决定整份 HTML 的阅读外壳；小节布局只决定局部图文关系。不要让 21 个小节共享同一个卡片骨架，也不要让每节都随机换样式。

## 小节布局

| 布局 | 适用条件 | 禁用条件 |
|---|---|---|
| `narrative_focus` | 无图、论证较长或需要连续阅读 | 不把多个指标硬塞进正文行内 |
| `narrative_emphasis` | 无图、摘要/结论/风险等需要视觉停顿 | 不连续使用三次；不放大缺证据的口号 |
| `chart_story_left` | 恰好一张图，文字量在预算内 | 多图、长来源、文字超过阈值 |
| `chart_story_right` | 同上，用于避免连续同构 | 同上 |
| `data_lead` | 多图、指标卡、密集比较或文字超预算 | 不把单一无比较数据伪装成复杂图表 |
| `table_analysis` | 章级策略明确要求结构化对照表 | 长段落、长来源未做列宽回退 |
| `risk_sequence` | 风险或情景章节需要逐项阅读 | 不把普通叙事强行卡片化 |
| `coverage_summary` | 整章缺少直接证据，被确定性压缩进研究覆盖表 | 不伪装成正文已完成；保留每个小节的审计键 |

左右图文只用于桌面宽屏。打印和窄屏必须按“标题 → 图/正文 → 来源 → 不确定性”的自然顺序回退。

## 抗重复不是随机化

布局变化按以下优先级决定：

1. 图表数量与类型；
2. 文字量；
3. 内容语义（时间序列、比较、风险、摘要等）；
4. 为避免连续三次同构而做的最小调整。

同一输入的输出必须稳定。颜色主题不是布局变化；只有阅读顺序、图文关系和信息层级变化才计为不同构图。

`table_analysis`、`risk_sequence` 与 `coverage_summary` 由模板结构表达，属于连续重复检查的豁免项；该豁免必须由目录的 `run_exempt_layouts` 明确驱动，不能依赖代码分支碰巧不处理。

## 中文与宽度

- 正文使用合理最大行宽；双栏文字列不得小于目录规定的最小宽度。
- `writing-mode: horizontal-tb`、`word-break: normal`；只允许长 URL 和不可分标识符 `overflow-wrap:anywhere`。
- 标题、数字和单位保持整体，不以窄表格单元格逐字折行。
- 小于桌面阈值时取消侧栏与图文双列，不通过缩小字号维持布局。
