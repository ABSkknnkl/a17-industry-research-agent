# 方法来源与取舍记录

本 skill 为本工程原创实现，没有复制下列项目的模板代码或品牌资产。采用的是抽象方法。

## `Investment-Agent-main`

采用：行业研究范围、市场/产业链/竞争/风险的结构意识；数据时效、完整性与异常显式标注。

不采用：以固定百分比机械忽略数据差异、默认用户数据永远最高优先、以中位数自动消解冲突。冲突数据必须保留来源与口径，是否采信由上游证据规则决定。

## Anthropic `financial-services`

采用：引用每个关键数字、统一比较口径、标记陈旧数据、先产出草稿并保留人工复核，以及“一份规范源、不同运行环境同步并检查漂移”的工程方法。

不采用：依赖本工程未配置的数据终端、MCP 或第三方金融数据库；不照搬单公司覆盖报告的固定页数和固定图表数量。

许可证：Apache-2.0。这里只记录方法来源，未复制实现代码。

## `awesome-html-slide-skills-main` 及其索引项目

采用：HTML 作为可审阅源、内容中间表示与渲染分离、先预览再完整生成、真实浏览器验证、紧凑元数据目录。

不采用：固定 `100vw × 100vh` 幻灯片画布、演示动画、大字号低密度和装饰性主题。长报告需要连续阅读、来源索引和移动端回退。
