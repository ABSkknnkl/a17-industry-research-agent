# 券商研报版式基准（基于 7 份真实研报实测提炼）

> 本文件是《真实研报 vs 本报告 版式对比报告》的可执行版本，用于直接替换渲染器设计 token。
> 数据来源：爱建证券（电子周报 / 电新策略 / 数据中心跟踪）、国信证券（商贸零售策略）、国新证券（光伏周报）、万联证券（交运跟踪）、吉图咨询（广西汽车），共 178 页 PDF 对象级实测。
> 阈值与 baseline 由 `scripts/style_benchmark_audit.py --baseline scripts/samples_baseline.json` 实测验证：6 份纵向真实样本的 baseline diff fails = 0；本报告 fails = 7。
> 横版报告 R7（吉图广西，334×188mm）因体裁不同不纳入 baseline，仅在 §1、§16 备注存在性。

---

## 0. 一句话诊断

**问题不是"不够漂亮"，而是体裁错位。** 当前实现用的是"产品发布会设计稿"的语言：满版深蓝封面、卡片化图表、多强调色、逐页自适应字号。真实券商研报的语言是：**白底、纯黑正文、单一品牌色、机构标识贯穿、字号边距恒定**。

## 1. 页面与版心（硬约束）

| 维度 | 目标值 | 真实区间 |

| 版心宽 | 170–180 mm | R1 175.8 / R2 170.0 / R3 179.9 / R4 180.5 |
| 内容区下边界 | 页脚顶线上方 ≥6 mm | R1 正文止于 268.8 mm |
| **页脚底距** | **≥ 12 mm（建议）** | audit 算法实测：R1 10.64 / R2 17.73 / R3 15.14 / R4 8.60 / R5 10.64 / R6 10.64 |

## 2. 字体与嵌入

| 维度 | 目标值 |
|---|---|
| 中文字体 | **单一字体族**：黑体（SimHei / 思源黑体）或微软雅黑（Microsoft YaHei） |
| 西文 / 数字 | Times New Roman / ArialMT（中文系字体族下的子字体） |
| 嵌入方式 | **Type0 / TrueType 子集**，基名形如 `XXXXXX+FontName` |
| Type3 字体 | **必须为 0** |

真实研报字体族（R1–R4 详细，R5/R6 已测，与 R1 同系）

| 报告 | 正文字体 |
|---|---|
| R1 爱建 8p | `MicrosoftYaHei` + `MicrosoftYaHei-Bold`（现代无衬线派） |
| R2 国信 14p | `SimHei`（**全篇唯一字体族**） |
| R3 国新 9p | `KaiTi` 正文 + `TimesNewRomanPS-BoldMT` 标题（传统衬线派） |
| R4 万联 13p | `KaiTi_GB2312` + `TimesNewRomanPSMT` |
| R5 爱建 70p | `MicrosoftYaHei`（与 R1 同系；70 页策略版） |
| R6 爱建 15p | `MicrosoftYaHei`（与 R1 同系；数据中心跟踪版） |

**当前实现：2055 个 Type3 字体对象，基名全部为空 → 等同"文字转曲线"，被 PDF/A 与印前流程拒绝。**

验收方法：
```python
fonts = [f for i in range(doc.page_count) for f in doc[i].get_fonts(full=True)]
type3 = [f for f in fonts if f[2] == 'Type3']
assert len(type3) == 0
assert all(f[3] for f in fonts)   # 基名非空
```

## 3. 字号阶梯

| 层级 | 目标值 | 真实区间（按本轮 8 份实测重新统计） |
|---|---|---|
| 封面主标题 | 18–22 pt | R1 20.1 / R2 22.0 / R3 16.0 / R4 18.0 / **R5 22.0** / **R6 22.0** / R7 44.1 |
| 目录标题 | 14–22 pt | R2 22.0 / R3 15.0 / R4 14.0 |
| H1 一级标题 | **15.5–16 pt，加粗** | R1 15.9 / R2 18.0 / R3 14.0 / R4 14.0 |
| H2 二级标题 | **14 pt，加粗** | R1 14.1 / R2 12.0 / R3 10.0 / R4 12.0 |
| **正文** | **10.4 pt 全篇恒定**（基准派）；或 **9.0 pt 全篇恒定**（爱建策略派，与 R5/R6 同） | R1 9.9 / R2 10.4 / R3 10.6 / R4 10.6 / **R5 9.0** / **R6 9.0** / R7 12.0 |
| **图表题注** | **= 正文字号**（差值 0.0） | R1 9.9 vs 9.9 / R2 10.4 vs 10.4 / R3 10.0 vs 10.6（差 0.6）/ R4 10.6 vs 10.6 / R5 9.0 vs 9.0 / R6 9.0 vs 9.0 |
| 来源行 | 8.0–9.0 pt | R1 9.0 / R2 8.1 / R3 8.0 / R4 9.0 |
| 页脚 | 7.5 pt | R1 7.5 / R2 6.5 / R3 7.0 / R4 8.0 |

**两条铁律**

1. **图表题注字号 = 正文字号。** 六份样本无一例外（R1 9.9=9.9、R2 10.4=10.4、R3 10.0≈10.6、R4 10.6=10.6、R5 9.0=9.0、R6 9.0=9.0）。当前实现题注 9.2pt 比正文小 1.0–1.6pt。

2. **正文字号跨页恒定。** 真实研报逐页众数字号固定（R2 全程 10.4、R5/R6 全程 9.0、R3 在 10.0/10.6 间切换但都在 0.6 之内）；当前实现在 8.9 / 9.2 / 9.5 / 9.6 / 10.2 / 10.8 之间交替。**取消渲染器的逐页字号自适应。**

### 3.1 正文派系的两条可选路线

- **国信 / 国新派**：正文 10.4–10.6 pt，数据密集场景
- **爱建策略派**（R5/R6）：正文 9.0 pt，长篇策略 / 跟踪场景

任选一条全篇锁定即可，但**禁止混用**。

验收方法：
```python
per_page = {i: Counter_of_sizes[doc[i]].most_common(1) for i in range(doc.page_count)}
assert len(set(per_page.values())) == 1
```

## 4. 行距与段落

| 维度 | 目标值 | 实测 |
|---|---|---|
| 正文行距 | **1.34×**（Word 单倍） | R1 1.82 / R2 1.35 / R3 1.51 / R4 1.47 / **R5 1.80** / **R6 1.73** / R7 1.80 |
| 段间距 | **不缩进 + 段间不加空行**（R1/R2/R4）/ **首行缩进 2 字符不空行**（R3 国新） | R1/R2/R4 段对齐左 / R3 段对齐左 / **R5/R6 段对齐 indent + justify 并存** |
| 段落对齐 | **左对齐**（或允许 indent 兼容） | R1 左/缩进/两端混存 → 左对齐是 R1 主；R3 左对齐为主 |
| 段落内字符 | 中文 black + 西文 Times（西文单独配） | R1-R6 均未做真正西文切换：cn=en=top 字体 |

**R5/R6 的特别发现**：R5（70 页）的 1.80 行距 + indent 是真实场景下的"书页感"长篇策略格式；不是错误，但与 R1/R2 的"短报告紧凑"格式不同。**本报告目标派系是国信 10.4pt / 1.34× / 不缩进**。

当前实现行距 1.39×，落在区间内；**此项已合格**。

### 7.3 坐标轴与网格

| 维度 | 目标 |
|---|---|
| 网格线 | 横向，中性浅灰；条形图可不设 |
| 刻度 | 整数量级优先（`-5/0/5/10/15%`）；百分比可用 2 位小数（`8.00/6.00`） |
| 数据标签 | 柱顶 / 柱下 / 条形端部 |
| 单位 | **写在题注**，不在绘图区悬标签 |

**当前实现在此项做法正确**（整数量级刻度、克制的横向网格），仅需把网格线 `#D9E1E7` 改为中性浅灰。

### 7.4 单位标注

真实研报：`图表106：全球主要企业针对全固态电池的设计和生产规划（单位：年）`

**当前实现：「亿元」在正文/单元格出现 36 次，「%」98 次，题注位置 0 次命中。**

### 7.5 同页图表密度

真实研报一页放 2–6 张图表（R3 p5 为 2×2 四图 + 双细线分组；R4 p5 一页 3 图；R5 p5 为 2×2 多图）。
**当前实现多数页只放 1–2 张，且被卡片 padding 进一步压缩。** 把可比较的图放进同页 2×2 网格。

实测各报告"图占版心高比"中位：
- R1 0.179 / R2 0.145 / R3 0.206 / R4 0.197 / **R5 0.188** / **R6 0.230** / R7 0.213
- 本报告约 0.18（受卡片 padding 压缩后），实际绘图区高度可能更小

## 8. 表格

| 维度 | 目标 |
|---|---|
| 表头 | **二选一**：品牌色深底 + 白字 ／ 白底黑字加粗 |
| 框线 | **二选一**：全网格细线（无斑马）／ 横线 + 斑马 |
| 斑马纹 | 仅在与"无竖线"组合时使用，不与全网格混用 |
| 对齐 | 首列 **左对齐**（公司名/类别），数字列右对齐或居中 |
| 单位 | **写在题注**，不在单元格重复 |

真实研报表头实测（第二轮复核后更正）：
- **爱建 70 页策略 p16 正文数据表**（R5）：`#0243A4` 品牌蓝深底 + 白字，行高 6.4mm（像素采样 `rgb(2,67,163)`）
- **国信 p13 投资评级表**（R2）：**白底黑字、无任何填充**（像素采样 y=95–120mm 全为 `(255,255,255)`）+ 全网格细黑线（5 条竖线）+ 无斑马纹

续表处理：当前实现审计跑了"表 5（续）"1 处命中（在本报告），对应真实研报 baseline 6 份均 0 命中；但**R5 长篇策略（70p）**本身有大量跨页表，其"续表"处理方式为：在表头行前一行加 `(续)` 标志。**本基准对短报告（<30p）的指示：跨页表与"续表"标记属于合理做法，长报告则按 R5 路线**。

**当前实现：表头 `#123A67` 藏青底 + 白字（与爱建 `#0243A4` 路线一致，保留）；首列实测左对齐（x=51pt，占列宽 6%，此前误记为"全部居中"，已更正）；但仅有横线、0 条竖线，同时叠加斑马纹 `#F7FAFB`，且单元格重复「亿元」。**
