# 研究报告图表设计规则

高质量图表要同时通过语义、编码、编排和印刷四层校验。“生成了一张图”不等于可视化完成。

## 先确定阅读任务

| 任务 | 首选 | 不适用时的回退 |
|---|---|---|
| 单指标 | 指标卡+同比/环比上下文 | 不画单柱、单点线或饼图 |
| 时间趋势 | 折线、面积或小多图 | 少于 3 个时点改指标对比 |
| 分类比较/排名 | 排序横向条形图 | 标签很短且类别少时可纵向柱图 |
| 同期多系列比较 | 并列柱或小多图 | 系列太多时改为热力图/分面 |
| 构成 | 环图、100% 堆叠条 | 类别多或差异小时改排序条形 |
| 分布/异常 | 直方、箱线或散点 | 样本少时改明细点图/表 |
| 多维轮廓 | 雷达图（少实体、同量纲或已标准化） | 实体/维度多时改热力图 |
| 产业关系 | 产业链/流程/关系图 | 关系无法证实时改分类列表 |
| 正负贡献 | 瀑布、正负条形 | 无共同基准时不画贡献图 |

## 视觉编码

- 条形和柱形默认从零起点；若业务必须截断，明确标记断轴。
- **全正数据的纵轴不得出现负值区间。** 若最小值 ≥ 0，坐标下界就是 0。让自动缩放把下界拉到负数，读者会以为存在负值。
- 排名图按值或业务顺序排列，不使用上游数据的偶然顺序。
- 比例值标明 0–1 还是 0–100%；数字精度、货币、时间和单位在同组图内统一。
- 正负值使用共同零线；不用红绿作为唯一区分手段。
- **中国市场语义：红 = 上行/正值，绿 = 下行/负值。** 这与欧美习惯相反；面向中文读者的涨跌、盈亏、同比图按此配色，并在图例或图下短注中说明语义，保证黑白打印也能靠形状辨认。
- 缺失值、不可比值和零值使用不同语义，不把缺失默认画成 0。
- 同一比较组共享坐标范围、色标和数字格式；若不共享，页面必须显式说明。
- 谨慎使用双轴；优先上下对齐的两张图或标准化指数，防止相关性错觉。

## 三类渲染后才暴露、必须在规划期就定好的缺陷

### 1. 发散条形图的标签碰撞

**触发组合**：水平条形 + 存在负值 + 长中文分类标签。

负值条会从零线向左延伸，而分类标签通常紧贴零线左侧；数据标签也贴在条形端点，于是「分类标签」与「数据标签」在同一水平带上重叠（实测会重叠成 `晶科能70056.11%` 这样的花屏）。

**结构性解法**（不要靠调间距凑）：

- 给分类标签一个**独占槽位**（固定宽度的左栏），绘图区从槽位右侧开始；
- 坐标域按 `±max|value|` **对称**设置，使任何条形都不会进入槽位；
- 数据标签放在条形内侧一端，并预留最小可读余量，避免贴边裁切。

规划期必须声明 `label_gutter` / `label_slot`；`validate_page_plan.py` 的 `DIVERGING_LABEL_GUTTER_MISSING` 会拦截遗漏。

### 2. 极值离群压扁可比序列

**触发条件**：`max|value| ÷ 次大|value| ≥ 8`。

例：归母净利润同比为 `-7056% / -106% / +22% / +25%`。同轴绘制时后三条会被压成紧贴零线的一条细线，读者既看不出数值也看不出差异；此时“画出来了”并不等于“可读”。

**降级处理**（择一并留痕）：

- 改为表格或注解表，给出全部原值，并说明各值不可直接横向比较；
- 若必须保留图形，使用小多图分面，让每组各自成轴；
- 对数轴只在业务上确实成立时使用，并显式标注。

在蓝图里声明 `max_abs_ratio` 与 `degrade_reason`（或把 `display_kind` 设为 `table` / `annotated_table` / `small_multiples` / `log_scale` / `split_axis`）。`validate_page_plan.py` 的 `OUTLIER_NOT_DEGRADED` 会拦截遗漏。

不要把“拆成两张各自独立坐标的图”当作修复：两张图不共享刻度时，读者无法判断跨图差异，等于把比较任务取消掉，必须在图下明确写出不可比较。

### 3. 刻度冗长与语义化标签

- 刻度用整数量级：`-7000 / -5000 / -3000 / -1000 / 0`。`-7,622.62%` 这类千分位小数刻度既占空间又无信息量，精确值留给数据标签或表格。
- 轴单位写在轴端或轴标签里，不要在每个刻度值后重复。
- 图例不要使用数据契约里的机器日期（`2025-12-31`），改用读者语言（`2025 年报 / 2026H1`）。
- 数据标签的精度要与正文一致：正文写 `0.76 元/W`，图内端点标签就不要写 `0.7554`。

## 标题、标签与图例

- 图题优先表达阅读对象和时间/口径；“结论式标题”只能引用已通过事实校验的上游结论。
- 长中文类别改用横向条形、直接标注或短语换行；不旋转成难读斜字，不一字一行。
- 系列少时在线末或标记旁直接标注；图例不要占用大块顶部绘图空间。
- 数据标签仅显示关键值、极值、末值或被文章引用的值；不在密集图上全量标注。
- 网格线弱化，坐标轴保留必要刻度；不用外框、阴影和底色同时包装每张图。
- 图内最小文字在最终 PDF 的 100% 缩放下必须可读（≥ 9px / 6.8pt）；轴标签与数据标签是常见的踩线位置。

## 图组和页面关系

- 一页先写一句已有事实支持的导语，再用图组回答；不让整页从无标题图表开始。
- 两张图对比同一维度时并排；对比同一时间序列时可上下对齐；三至四张图使用小多图或 2×2。
- 一大两小只在主结论与两项支撑证据确实存在时使用，不按图表先后顺序随意放大。
- 小多图的标题线、绘图区、零线、来源线对齐；统一图例移到图组层。
- 页内图表数量由最终字号和标签可读性决定，不为达到固定 2×2 而缩小到不可读。

## 印刷与降级

- 在最终 PDF 100% 缩放下检查最小字号、细线、颜色对比和背景保留，不以浏览器放大预览代替。
- 设置打印色彩保留，同时确保黑白打印仍能通过形状、线型或直接标注辨认。
- 数据不足、序列过密或标签无法合法排布时，降级为指标卡、表格或简洁空状态；不生成伪图表。
