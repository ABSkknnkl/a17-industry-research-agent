# 编辑压缩与阅读层级

页面编排不是把所有上游文字等量排出。目标是让读者先看到结论、再看到证据、需要时才进入完整口径和审计信息。

## 五级信息层

- `headline`：页面唯一主结论或章节主题。
- `lead`：支撑主结论的 1–3 条关键数字或判断。
- `support`：正文论证、主图表和必要表格。
- `detail`：完整口径、方法、长注释、次要图表和来源索引。
- `audit`：机器状态、证据缺口、未生成原因、内部问题码与复检日志。

对外正文以前三级为主。`detail` 通常放页下短注或附录，`audit` 默认不进入对外版。

## 可以压缩的冗余

- 同一结论在封面摘要、执行摘要、章节摘要和图注中重复：保留首次完整表达，其余使用短引导或内部链接。
- 每张图重复“图表类型、生成目的、展示说明”：正文只保留图号、标题、必要口径和来源。
- 每张结论卡都重复置信度、不确定性和来源芯片：改为页级统一说明，仅对异常项单独标注。
- 多个章节都只有“暂无材料”：合并为一张“研究覆盖与数据限制”矩阵，保留全部章节 ID，不为每个空状态生成独立大卡。
- 内部英文状态码、字段名和处理过程：放内部审计版，对外版仅保留必要风险提示。
- 内容完全相同的连续表格行：成组为“X-01 等 N 项”一行并在表下注明归并关系，不要逐行复制同一句处理说明。

## 确定性净化：不要靠手工逐句改

冗余不是靠通读发现的，靠脚本发现。渲染前必须运行 `scripts/text_hygiene.py`：

```bash
python3 scripts/text_hygiene.py inventory.json --write-fixed inventory.fixed.json
python3 scripts/text_hygiene.py inventory.fixed.json   # 必须 clean=True
```

它把下列四类问题变成可执行判据。词表与规则集中在 `scripts/text_rules.py`，扩展时改那里，不要在渲染器里另写一套。

### 1. 重复段落

正文归一化（去空白 + NFKC）后按 4-gram Jaccard 相似度比较；`≥ 0.90` 且长度 `≥ 40` 字判为重复。保留首次完整表达，其余条目合并并把被合并 ID 写入 `content_dispositions`。

### 2. 空话模板

同一句式在不同章节反复出现时，读者得不到任何新信息，纯属版面填充。典型句式：

- `当前可用证据不足以对 <X> 形成可靠事实判断，本节保留研究位置，待补充数据后复核。`
- `当前证据台账无法支撑 <X>。`
- `资料不足，不补造事实或数字。`

**判据是句式下标，不是原文**——换个主语仍是同一句空话，必须一起归并。规则：**同一句式全文只保留一次**（首次出现是正常结论，第 2 次起即缺陷），其余并入覆盖矩阵。被归并章节的缺口仍通过附录矩阵逐条可追溯。

### 3. 机器字段与内部标识

以下内容一旦进入对外阅读层即判 `major`，必须改写为读者表述或下沉附录：

| 类别 | 示例 | 改写方向 |
|---|---|---|
| 数据契约字段 | `missing_inputs` / `period_end` / `available_at` / `scope` / `dimension_coverage` | 数据限制清单 / 数据截止日 / 数据可用日 / 统计口径 / 维度覆盖记录 |
| 编排智能体编号 | `Agent 4 章节质量门未通过` | 第七章情景与结论尚未通过内部章节质量门 |
| 状态码 | `competition · partial` / `unavailable` / `UNSUPPORTED-METRICS` | 竞争格局 · 部分支持 / 资料不足 / 指标口径不受支持 |
| 内部标识 | `E-f4a2fbacfb02b33e` / `CALC-237B554E…` / `CHART-…` | 删除；追溯性由附录证据索引承担 |
| 管线描述 | “报告由数据解读智能体的结构化结论…确定性组装” | “本报告由结构化研究结论、已校验图表与分章正文组装而成” |

注意：括号**不是**保护伞。`（E-f4a2fbacfb02b33e仅覆盖 2023-11-15 单点）` 这种“ID 后面跟着说明”的写法同样要清掉 ID，只保留说明。

### 4. 数值精度

同一条指标在正文里出现两种精度（`0.76 元/W` 与 `0.7611 元/W`）本身就是缺陷。正文统一到业务精度：

| 类型 | 正文精度 | 例子 |
|---|---|---|
| 百分比 | 2 位小数 | `5.1848%` → `5.18%` |
| 金额 | 亿元 / 万元 + 2 位小数 | `66974548527.63元` → `669.75亿元` |
| 无单位高位裸数（≥10 位） | 按金额处理 | `-12423798001.78` → `-124.24亿元` |
| 单位价格 | 2 位小数 | `0.7611 元/W` → `0.76 元/W` |

审计级完整精度不删除，下沉到内部附录并保留可追溯 ID。

图表内标签的精度要与正文一致；正文写 `0.76`，图内端点就不要写 `0.7554`。

## 不可压缩的内容

- 只出现一次的关键数字、单位、时间范围、样本范围和比较基准。
- 会改变结论边界的限定词、不确定性和风险。
- 引用指向和事实与证据的映射。
- 比较图中的口径差异、可比范围和必要的缺失值说明。

## 显示文案约束

- 封面只做身份与主题建立；执行摘要、完整元数据、风险和审核状态不全部堆在封面。
- 封面与页脚不得出现生成管线名、skill 名或编排智能体名。
- 页标题尽量一行，最多两行；标题换行按语义短语，不在数字和单位之间断开。
- 摘要卡一卡一结论；文字超出容器预算时改用通栏摘要或正文，不继续压窄卡片。
- 图题说明“这是什么”，页级导语说明“为什么看它”；不在图内、图题、图注三处重复同一句话。
- 来源优先一行。超长 URL、全称和访问日期放来源索引，图下使用短来源名与编号。
- 目录页的脚注不要写实现流程说明（“页码在最终分页后回填校验”这类话属于生产说明，不属于读者需要的信息）。

## 压缩后的安全校验

1. 建立原始 `fact_id`、`claim_id`、`citation_id` 清单。
2. 对比编辑前后的数值、单位、日期、实体名与限定词。
3. 每个唯一事实必须在正文或明确可达的附录中保留。
4. 若缩写会产生新判断、改变结论强度或丢失证据，必须回退到原文。
5. 跑 `scripts/text_hygiene.py` 复检，确认 `clean=True`；再用 `scripts/validate_page_plan.py` 确认所有原始内容 ID 都能在块引用或 `content_dispositions` 中找到归属，没有静默丢失。
