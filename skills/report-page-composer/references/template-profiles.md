# 模板配置文件（Template Profiles）

> 在券商研报体裁基准内定义的多元化视觉预设。每个预设是一组协调的设计决策，
> 包括品牌色、封面布局、图表排列偏好、间距密度和表格表头风格。
> 所有预设**严格遵守 house-style-benchmark.md 的体裁硬约束**。

## 体裁不可变约束（所有预设共享）

以下约束是基准线，**任何预设都不得突破**：

- 封面与内页白底
- 正文纯黑 `#000000`
- 强调色仅 1 个品牌色（预设间可不同，预设内不可多色）
- 图表不包卡片（白底直排）
- 图表题注字号 = 正文字号
- 字号、边距、行距全篇恒定
- 页眉机构标识 ≥6mm；页脚距底 ≥12mm
- 对外正文不含内部流程语言

## 四种预设

### 1. `classic_research` — 经典研报型

传统券商研报风格，信息密集、层次分明、节奏稳健。

| 维度 | 取值 |
|---|---|
| 品牌色 | `#0243A4`（深蓝） |
| 语义红 | `#D33333` |
| 中性灰 | `#595959` |
| 正文字号 | 10.4pt |
| H2（章标题） | 15.9pt 加粗 |
| H3（节标题） | 12.5pt 加粗 |
| 行高 | 1.34 |
| 封面布局 | 双栏密集（meta-row + 结论并列） |
| 图表偏好 | 均衡（按数量自动选 hero/two_up/hero_plus_two/two_by_two） |
| 间距 | 均衡（section margin 4mm、chart margin 5mm） |
| 表头风格 | 实色填充（品牌色底白字） |

适用场景：标准研报、多章节深度分析、量化与定性内容均衡的报告。

### 2. `modern_analysis` — 现代分析型

在研报基准上更注重阅读节奏，标题更大、章节间距更宽、双图对比优先。

| 维度 | 取值 |
|---|---|
| 品牌色 | `#0A5C5C`（青色） |
| 语义红 | `#C0392B` |
| 中性灰 | `#595959` |
| 正文字号 | 10.4pt |
| H2（章标题） | 16pt 加粗 |
| H3（节标题） | 12pt 加粗 |
| 行高 | 1.38 |
| 封面布局 | 标题优先（大标题 + 标语 + 双栏 meta 下方） |
| 图表偏好 | 偏好并列（有 2 张图时优先 two_up） |
| 间距 | 宽裕（section margin 5mm、chart margin 6mm） |
| 表头风格 | 实色填充（品牌色底白字） |

适用场景：新兴产业分析、消费/科技行业报告、面向投资决策委员会的简报。

### 3. `data_intensive` — 数据密集型

量化内容占比高的报告，以表格、指标卡、大图为主，间距更紧凑。

| 维度 | 取值 |
|---|---|
| 品牌色 | `#1B3154`（深藏蓝） |
| 语义红 | `#C0392B` |
| 中性灰 | `#595959` |
| 正文字号 | 10.4pt |
| H2（章标题） | 15.5pt 加粗 |
| H3（节标题） | 12pt 加粗 |
| 行高 | 1.32 |
| 封面布局 | 密集 meta-row（更多键值对、三列布局） |
| 图表偏好 | 偏好单图（优先 single_hero 获取最大尺寸） |
| 间距 | 紧凑（section margin 3mm、chart margin 4mm） |
| 表头风格 | 实色填充（品牌色底白字） |

适用场景：财务报表分析、大宗商品数据月报、以表格和指标卡为主的周报。

### 4. `narrative_flow` — 叙事流畅型

定性论述为主的报告，更注重文字阅读体验和章节衔接。

| 维度 | 取值 |
|---|---|
| 品牌色 | `#7A1F3D`（酒红） |
| 语义红 | `#C0392B` |
| 中性灰 | `#595959` |
| 正文字号 | 10.4pt |
| H2（章标题） | 16pt 加粗 |
| H3（节标题） | 13pt 加粗 |
| 行高 | 1.40 |
| 封面布局 | 宽标题（大标题 + 核心结论叙事段落） |
| 图表偏好 | 偏好单图配文（single_hero + 更多上下文文字） |
| 间距 | 宽裕（section margin 5mm、chart margin 6mm） |
| 表头风格 | 简约表头（浅灰底加粗，不使用品牌色填充） |

适用场景：行业深度叙事、政策分析、方法论与框架型报告。

## 选择规则（确定性）

当 `requested_profile = "auto"` 时，按以下规则推荐：

1. 量化内容占比 ≥70% 且表格候选 ≥3 → `data_intensive`
2. 定性论述占比 ≥60% 且图表 ≤4 → `narrative_flow`
3. 图表、数据与解释均衡且章节 ≥5 → `modern_analysis`
4. 其他 → `classic_research`

用户可显式指定预设，系统记录推荐与实际选择的差异作为覆盖警告。

## 预设切换的渲染约束

- 同一份报告**只能使用一个预设**，全篇统一。
- 渲染器通过 CSS 自定义属性（`--brand`、`--red`、`--muted` 等）接收预设值，
  不在模板中硬编码颜色。
- 预设不改变 HTML 结构、Jinja 绑定、`data-*` 语义属性或 `render_contract`；
  只改变 CSS 变量和少量布局类名。
- 预设不得引入新的字体族、新的字号阶梯或新的页面尺寸。
- 预设切换后必须重新运行 `style_benchmark_audit.py --baseline` 验证。

## 与 house-style-benchmark 的关系

| 基准维度 | 预设如何处理 |
|---|---|
| Type3 字体 = 0 | 所有预设共用 `@font-face local()` 方案，不因预设变化 |
| 正文字号恒定 | 所有预设使用 10.4pt 正文；预设间不改变 |
| 正文纯黑 | 所有预设正文色 `#000000`；预设仅改变品牌色 |
| 强调色 = 1 | 每个预设恰好 1 个品牌色 + 1 个语义红（红用于风险标注，不计入强调色） |
| 图表无卡片 | 所有预设共用无卡片直排方案 |
| 封面白底 | 所有预设封面白底；布局密度不同但背景均为白色 |
| 页眉标识 ≥6mm | 所有预设共用 Playwright header_template 方案 |
| 页脚距底 ≥12mm | 所有预设共用 Playwright footer_template 方案 |

## 扩展预设

添加新预设时必须：
1. 在本文件定义全部维度取值；
2. 确保通过 `style_benchmark_audit.py --baseline` 全部 7 维度；
3. 在 `visual.py` 的 `_PROFILE_CONFIG` 注册 CSS 变量映射；
4. 在 `report.html.j2` 中无需修改（CSS 变量驱动）；
5. 更新 `report_editor_context` 的 `allowed_template_profiles` 列表。
