## 总览

| 测试项 | 结果 | 说明 |
|--------|------|------|
| 智能体1 + iFinD 连通性 | **通过** | 真实API连接成功，质量门通过，日均获取 ~140-160 条证据 |

## 话术详情

### 话术1：杜邦财务+边界降级+自动绘图

**校验点结果：**

| 校验点 | 状态 | 说明 |
|--------|------|------|
| 固定公式执行 | **部分通过** | 杜邦ROE、毛利率、营收同比等公式可执行，但仅对"富奥股份"（非指定公司） |
| 期初缺失自动降级 | **未触发** | 宁德时代仅1期有效财务数据，无法同比；但期初缺失日志未显式输出 |
| 携带公式/原始证据ID | **通过** | 计算指标 `inputs` 中携带完整证据链 |
| 计算结果流转至智能体3 | **受阻** | 智能体2 LLM 失败 → 无 `chart_candidates` → 智能体3退化为兜底 |

**关键问题：**
- `_canonical_metric` 子串匹配将"存货周转天数(69.26天)"误判为"存货余额" → 周转率 = 6613亿 / 69.26 ≈ 103亿次（荒谬）
- 宁德时代只有1期2025年报财务数据，无法计算同比、杜邦（需期初+期末）
- 返回数据以"富奥股份"（板块成分股）为主，非目标公司

## 问题根因分析

### 级别1：智能体1数据口径问题（最严重）

| 编号 | 根因 | 影响 |
|------|------|------|
| A1 | iFinD 返回以板块成分股数据为主，非指定目标公司 | 宁德时代仅有15条证据（含12条非财务），比亚迪无存货/应收余额 |
| A2 | unit 字段大量为"未提供"而非"亿元"/"元" | 智能体2 `_compatible_units` 比较时可能因空字符串误判 |
| A3 | 衍生指标（存货周转天数、毛利率）与原值指标混淆 | `_canonical_metric` 子串匹配将"存货周转天数"误判为"存货余额" |
| A4 | 市占率/产量/产能/销量等专题指标缺失 | CRn、产能利用率、产销率无法计算 |

### 级别2：智能体2 计算模块问题

| 编号 | 根因 | 影响 |
|------|------|------|
| B1 | `_canonical_metric` 子串匹配无排除逻辑 | 衍生指标（周转天数、毛利率）混入原值池，计算荒谬 |
| B2 | `_previous_annual_period` 仅检查 330-400 天间隔 | 多期数据但间隔非整年时跳过，减少可用计算 |
| B3 | 无 unit 缺失时的单位推断逻辑 | unit="未提供" 时 `_compatible_units` 可能返回空字符串相等 |

### 级别3：智能体2 LLM 问题

| 编号 | 根因 | 影响 |
|------|------|------|
| C1 | DeepSeek-V4-Pro 输出超 8192 token 被截断 | `LengthFinishReasonError`，结构化 JSON 不完整 |
| C2 | 158条证据 + 25个数据集 + 42个计算指标超过 LLM 单次处理能力 | 上下文过长，需分段处理 |

### 级别4：智能体3 链路问题

| 编号 | 根因 | 影响 |
|------|------|------|
| D1 | 无智能体2候选时退化为兜底 | 生成图表与话术需求无关（如"经营活动产生的现金流量净额对比"） |
| D2 | 图表互斥规则逻辑正确但无数据验证 | 所有互斥相关校验点因缺乏候选而无法触发 |

## 修复建议

### 优先级P0（数据口径）

1. **修复 `_canonical_metric` 子串匹配**：排除包含"周转天数""周转率""同比增长率""毛利率"等衍生指标，或增加 `metric_name` 精确匹配权重
2. **iFinD 查询优化**：对 `focus_companies` 明确指定时，限制查询范围为指定公司而非板块成分股
3. **unit 字段缺失处理**：iFinD 返回空 unit 时，根据数值量级推断单位为"亿元"（默认财务单位）

### 优先级P1（LLM）

4. **智能体2 LLM 分段处理**：超过 8K token 时，将证据按 scope/period 分组后分批调用 LLM，再合并结果
5. **增加 `max_output_tokens` 配置**：从 8192 扩大到 16384 或使用 `segmented_threshold_chars` 提前分段

### 优先级P2（验证）

6. **市占率/产能数据源补充**：iFinD 的 `hithink_industry_query` 不返回企业级市占率，需补充 `hithink_finance_query` 的专项查询或使用问财自然语言查询
7. **季度/年度口径混用检测**：在 `_calculate_period_metrics` 中增加 `period_end` 是否为12月31日的校验
