三种情景

  • 基准情景：AI算力需求增长 → 数据中心GPU出货量提升 → 收入增长 → 规模效应和产品组合优化 → 毛利率稳定 → 净利润增长；触发条件：季度数据中心收入同比增速维持在50%以上 / GAAP毛利率稳定在73%-76%区间 / 主要云厂商资本开支指引未出现大幅下调
  • 乐观情景：AI需求超预期 → 订单积压增加 → 收入加速增长 → 规模效应增强 → 毛利率提升 → 净利润超预期增长；触发条件：数据中心收入同比增速超过80% / 毛利率连续两个季度超过76% / 新客户或新地区（如中东）大规模采购
  • 悲观情景：需求放缓或竞争加剧 → 出货量下降或价格承压 → 收入增速放缓 → 毛利率下降 → 净利润增速大幅放缓；触发条件：数据中心收入同比增速降至30%以下 / 毛利率跌破68% / 主要客户自研芯片比例大幅提升

核心风险

  • AI需求放缓风险：若全球AI资本开支增速显著放缓，或出现AI泡沫破裂，数据中心业务增长将大幅减速，影响整体营收和利润。
  • 出口管制风险：美国对华出口管制若进一步升级，将限制英伟达在中国市场的销售，影响收入。
  • 竞争加剧风险：AMD、英特尔及云厂商自研芯片（如谷歌TPU、亚马逊Trainium）的竞争可能侵蚀市场份额，导致价格压力和毛利率下降。
  • 供应链风险：先进制程产能（台积电CoWoS）和HBM供应紧张可能限制出货量，影响收入增长。
  • 技术迭代风险：若下一代架构（如Rubin）推出延迟或性能不及预期，可能影响客户采购决策。
  • 估值风险：当前估值已反映高增长预期，若业绩不及预期，股价可能大幅回调。
