# 地缘与供应链安全风险写作

- **风险三要素闭环**：论述地缘或政策摩擦风险时，段落必须包含：① 触发条件（如关税税率提升、出口管制扩大）；② 传导路径（上游零部件进出口 → 成本攀升 → 毛利承压）；③ 行业应对冗余度（国产替代进度与切换周期）。
- **情景化分层阐述**：设立乐观（关税豁免/温和演进）、基准（局部限制/常态化摩擦）、极端（全面封锁/断供脱钩）三档情景，明确不同情景对行业产值与毛利的量化弹性影响。
- **客观防御视角**：指出出海建厂推进程度、关键元器件国内第二供应商验证状态，避免笼统的恐慌情绪化表述。
