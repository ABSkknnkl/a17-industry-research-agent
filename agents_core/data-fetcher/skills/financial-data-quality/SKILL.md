# 财务数据质量规划

本 Skill 只定义客观财务数据的采集与校验要求，不对公司评级，不给出健康区间、买卖建议或主观结论。

筛选来源：`skills包/财务报表深度解读/financial-statement`，已按本项目的数据边界收窄。

规划财务查询时优先明确公司实体与证券代码，并按需要覆盖：

- 利润表：营业收入、营业成本、期间费用、营业利润、净利润；
- 资产负债表：现金、应收、存货、固定资产、负债、所有者权益；
- 现金流量表：经营、投资和筹资活动现金流；
- 衍生指标：毛利率、净利率、资产负债率、周转率、ROE；
- 元数据：报告期、披露日、币种、单位、合并口径、审计状态和来源。

确定性融合阶段可检查资产等于负债加权益、现金变动与现金流等勾稽关系。无法解释的差异应保留原值并进入问题或冲突台账。
