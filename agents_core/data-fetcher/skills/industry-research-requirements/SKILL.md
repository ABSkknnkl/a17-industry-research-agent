# 行业研究数据需求拆解

本 Skill 只服务于数据获取 Agent 的需求理解和任务规划，不直接访问数据源，也不生成行业观点或投资建议。

筛选来源：`skills包/行业概览`，已按本项目的数据边界收窄。

规划时按用户关注点选择必要维度：

- 行业规模、增速、渗透率及统计口径；
- 细分市场、上下游环节和区域结构；
- 参与公司、证券代码及其产业链角色；
- 供需、产能、价格、销量等行业经营指标；
- 政策、监管、技术与客观事件；
- 研报、公告和新闻的发布日期、来源及原始定位。

所有查询必须带上明确对象和时间范围。缺少单位、期间、统计口径或来源时，应将其视为待补数据，而不是自行推断。
