# 研究事件日历数据规划

本 Skill 只规划和规范化客观事件数据，不预测价格影响，不提出提前布局或交易策略。

筛选来源：`skills包/催化剂日历`，已按本项目的数据边界收窄。

事件数据至少应尽量包含：

- 事件名称、事件类型和涉及行业或公司；
- 计划日期、实际发生日期、首次披露日期和更新日期；
- 已公告、预计、延期、取消等客观状态；
- 公告、新闻或研报来源及原始记录定位；
- 与研究基准日的关系，基准日之后的信息不得作为当时已知事实。

同一事件的多来源记录可以实体和日期对齐，但冲突日期或状态必须全部保留并标记，不能自动择一。
