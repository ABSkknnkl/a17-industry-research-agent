# 科技炒作与基本面评估方法

只基于输入中的财务、研报、行情与业务事实进行估值匹配度与商业化落地检验，不外推未经验证的远期市场空间，不给出买卖投资建议。

- **增长与估值匹配检验**：对比样本企业的营收复合增速（CAGR）与当前市盈率（PE）/市销率（PS）倍数，分析 PEG 与估值分位是否脱离行业平均中枢。
- **造血与盈利质量检验**：重点核查经营活动产生的现金流量净额、自由现金流是否持续为负；检验净利润中政府补助、投资收益与主营利润占比。
- **资本效率与研发真实性**：核实研发费用占营收比重，排查研发费用是否存在过度资本化美化当期利润；结合主营业务构成核查相关概念业务在总营收中的真实占比。
- **泡沫与落地分化归纳**：
  - 高估炒作特征：估值处于历史极端高位但核心业务收入微弱、经营现金流持续流出、依赖非经常性损益。
  - 基本面支撑特征：细分核心产品订单放量、毛利率企稳或扩张、具备规模效应驱动的经营杠杆。
- 所有估值与财务比率必须逐一对应证据记录，严禁猜测未经审计的商业化订单。
