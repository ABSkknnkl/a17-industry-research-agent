# 盈利预期修正与景气动能解读方法

只基于输入中的研报预测数据、业绩预告与实际披露财务报表提取预期修正事实，不补取外部预测，不给出交易择时。

- **一致预期修正广度分析**：统计分析师对行业代表性公司净利润与营收预期的调整方向（上调家数占比 vs 下调家数占比），识别景气度上行或承压信号。
- **业绩意外度量（Earnings Surprise）**：比对财报实际披露数值与前期一致预期中枢，计算超预期（Beat）或低于预期（Miss）的偏离百分比。
- **预期修正幅度与连续性**：识别近期是否存在密集上调或下修净利预测的情形，判断行业盈利拐点是属于脉冲式情绪驱动还是长期经营改善。
- **与管理层经营指引交叉比对**：将研报一致预期的变动与公司披露的经营规划、在手订单及出厂指引进行互相印证。
- 提取的所有预测中枢、偏差率和分析师覆盖家数必须逐一引用原始研报与数据记录 ID。
