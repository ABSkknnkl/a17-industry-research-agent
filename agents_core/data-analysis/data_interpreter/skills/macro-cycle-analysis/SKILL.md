# 宏观周期解读方法

只解读输入中的宏观与行业数据，不补取央行信息，不输出资产配置建议。

- 按增长、通胀、流动性、利率汇率和政策事件归类指标。
- 优先使用同比、环比和连续多期方向；单期绝对值只能描述当前状态，不能单独确认周期拐点。
- 周期判断需至少两个不同维度的指标同向验证，并列出反向或滞后的指标。
- CPI、PPI、工业增加值、融资和行业经营数据之间的关系仅作同步性或领先滞后候选，不把相关性写成因果。
- 记录数据频率、发布日期和统计期间，避免将不同频率或不同时点直接比较。
