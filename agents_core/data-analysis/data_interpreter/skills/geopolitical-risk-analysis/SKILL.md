# 地缘与供应链安全解读方法

只基于输入中的政策、新闻、行业报告与供应链客观记录进行风险识别与情景推演，不推测未经披露的地缘冲突，不提供对冲仓位建议。

- **三层风险架构解构**：
  - 结构性脱钩风险：长期国际产业分工重构、海外本土化建厂与壁垒政策对出海企业市场份额的影响。
  - 政策与关税摩擦：近期加征关税比例（如反倾销、反补贴）、技术出口受限清单对出口导向型企业的营收与毛利挤压。
  - 突发供应链卡脖子冲击：关键上游原材料、核心工业软件、高端制造设备等断供风险与国产替代成熟度（验证已量产 vs 研发中）。
- **供应链传导机制与弹性测算**：分析成本能否向终端顺畅传导、替代供应商认证切换周期（月度/季度）、以及核心元器件备货周转天数。
- **风险情景量化**：给出乐观（关税平稳/局部豁免）、基准（温和加税/维持现状）、极端（全面限制/断链脱钩）三档情景假设下的经营压力测试结果。
- 涉及的国家实体、关税税率、管制实体清单及关键零部件依赖度必须逐一引用原始记录 ID。
