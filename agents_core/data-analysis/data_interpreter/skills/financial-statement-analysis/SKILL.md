# 财务报表解读方法

只分析输入数据集中的事实，不补取财报、不套用缺少字段的公式，也不根据单个异常直接推断舞弊。

优先检查：

- 收入、利润与经营现金流的方向是否一致；现金流持续弱于利润时标为盈利质量观察项。
- 应收、存货增速是否显著高于收入增速；必须引用相同或可比期间。
- 毛利率、净利率、ROE、资产周转率和权益乘数的变化，用于拆解盈利驱动。
- 货币资金与有息负债、商誉与净资产等组合关系；字段不足时明确“无法验证”。
- 所有派生比率写明分子、分母、期间和证据记录，不使用行业统一“健康阈值”替代同业或历史比较。

输出应区分“已验证事实”“描述性异常”和“待补数据”，不得形成投资建议。
