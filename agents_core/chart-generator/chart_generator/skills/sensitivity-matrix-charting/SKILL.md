# 敏感性矩阵与弹性热力图规范

- **坐标轴与维度设计**：
  - 横轴（X轴）与纵轴（Y轴）必须分别代表两个独立的经营假设变量（如产品销售单价 ASP 变动率 vs 核心原材料采购成本变动率）；
  - 变量步长区间应合理对称（如 -10%, -5%, 0%, +5%, +10%），中心点必须显式标出基准情景（Base Case, 0% 变动）。
- **色阶与数值映射**：
  - 矩阵单元格数值表示净利润变动额（万元/亿元）或净利润增减弹性百分比；
  - 视觉映射（visualMap）采用双向发散色系：正向利润增厚呈现翠绿/藏青，负向利润挤压呈现朱红/橘红，零变化处为中性白或浅灰；
  - 必须标明单位（% 或 币种单位），并显式展示零轴分界线或盈亏平衡隔离带。
- **证据与脚注合规**：
  - 矩阵所依赖的基准营业成本占比与毛利率必须来自底层真实财报；
  - 在图表底部添加明确的静态假定声明（如“假定其他期间费用率与销量保持不变”）。
