# 估值-增速四象限定位图规范

- **坐标轴定义与零轴处理**：
  - 横轴（X轴）采用营收或归母净利润的复合增长率（CAGR %），允许负增长区间，严禁右移或隐藏负增速；
  - 纵轴（Y轴）采用动态市盈率（PE-TTM）或市销率（PS-TTM），倍数必须保留统一量纲（倍）。
- **四象限基准中枢线**：
  - 必须在横轴与纵轴上分别设置参考中枢线（行业平均增速线 markLine 与 行业中位数估值线）；
  - 四象限金融语义明确：
    - 第一象限（高增长、高估值）：高景气领军标的，需警惕预期透支风险；
    - 第二象限（低增长、高估值）：高估值/纯概念炒作风险区；
    - 第三象限（低增长、低估值）：周期低谷或成熟价值区；
    - 第四象限（高增长、低估值）：高性价比成长龙头（GARP 策略核心）。
- **气泡维度与标识规范**：
  - 散点气泡大小（symbolSize）可映射为企业总市值，增强多维横截面信息量；
  - 气泡旁需清晰标注证券简称，tooltip 必须同时完整显示公司代码、市值、增速与估值倍数。
