# 图表选型与组合规范

- 【启用范围】：只允许生成 line、bar、combo、area、pie、radar 六种图表；其他类型必须抑制。
- 【图表多样性原则】：在真实数据适配的前提下，从六种启用图表中组合表达，不为凑类型而造图。
- 【双轴组合图 combo】：当同时展示规模量纲（如营收、利润总额，左轴柱状）与比率量纲（如同比增速、利润率，右轴折线）时，必须使用双轴组合图，以揭示规模扩张与成长斜率的背离或共振。
- 【折线图 line】：用于连续时间趋势，历史值与预测值须明确区分。
- 【柱状图 bar】：用于实体排名、横向比较和正负分化；长标签可切换为水平布局，正负值必须保留零轴。
- 【面积图 area】：用于强调连续时间趋势的规模轮廓，不与同一数据的折线图重复生成。
- 【环形饼图 pie】：展示业务板块构成、价值量分布或环节份额，采用中心留白环形布局。
- 【多维竞争力雷达图 radar】：用于多维度综合画像（如规模、成长、盈利、现金流、研发强度），必须明确标注样本内 0—100 标准化方法。
- 没有安全表达方式时主动在 suppressed_charts 中抑制候选并说明原因，严禁伪造或虚构数据。
