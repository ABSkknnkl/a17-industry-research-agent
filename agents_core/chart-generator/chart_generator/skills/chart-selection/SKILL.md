# 图表选型与组合规范

- 【图表多样性原则】：严禁全篇单一采用简单柱状图！一份专业的金融产业研报必须根据不同财务与产业分析维度，至少涵盖 4 种以上不同形态的专业图表组合。
- 【双轴组合图 combo】：当同时展示规模量纲（如营收、利润总额，左轴柱状）与比率量纲（如同比增速、利润率，右轴折线）时，必须使用双轴组合图，以揭示规模扩张与成长斜率的背离或共振。
- 【四象限定位散点图 scatter / bubble】：当在跨实体截面上比较两个核心维度（如“营收体量 vs 净利率”、“成长性 vs 盈利性”）时，使用散点图。配合中位数十字参考线划分四大定位象限，揭示企业竞争梯队。
- 【正负偏离发散条形图 diverging_bar】：当比较包含正负分化特征的指标（如各企业经营性现金流正负分化、净利润正负增速）时，必须使用带有清晰零轴基线的发散条形图。
- 【环形结构图 donut】：展示业务板块构成、价值量分布或环节份额时，采用中心留白环形图，中心标注总量，右侧配置详细百分比与绝对值图例。
- 【多维竞争力雷达图 radar】：用于多维度综合画像（如规模、成长、盈利、现金流、研发强度），必须明确标注样本内 0—100 标准化方法。
- 【产业链价值拓扑图 industry_chain】：梳理上中下游传导关系时，使用有向拓扑图，标明各环节代表企业与产品定位。
- 【横向排名对比 horizontal_bar / bar】：用于企业关键指标的单维横向排序对比，突出标的企业相对行业头部的位置。
- 没有安全表达方式时主动在 suppressed_charts 中抑制候选并说明原因，严禁伪造或虚构数据。
