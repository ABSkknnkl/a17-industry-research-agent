# 竞赛答辩封面 · 分层合成制作说明

> 适用项目：【A17】基于同花顺问财 SkillHub 的行业研究报告智能生成与人机协同优化系统
> 视觉参考：他人最终版竞赛答辩封面（仅借版式气质与层次关系，不借文字、标识、品牌、具体素材）
> 约定日期：2026-11-12

---

## 0. 一句话原则

**生图只出一张「什么信息都不带」的底图；所有能被读出来的东西，全部在 PPT 里用矢量形状 + 文本框重新搭一遍。**

判断分层是否做对，只有一个测试：**把底图整层删掉，剩下的元素层放在纯白背景上仍然完整、仍然能看懂**。如果删掉底图就散架，说明又把信息烧进位图了。

> **重要（20:34 更新）**：以上四层手工叠加的做法在执行端卡住了——用户反馈「生成的背景层我都不知道怎么配前景层」。因此已改为 **双图配对方案**：让别的 AI 一次交付「不透明背景图 A + 透明底前景图 B」，两张同尺寸同锚点，B 叠到 A 上就是完整封面视觉底稿，文字仍由 PPT 文本框叠加。
> **以 `封面底图提示词-交接任务书.md`（v2 双图配对版）为准**，本文件保留作为分层原理与坐标锚点的参考；`L0_底图生图提示词.txt` 的三版单图提示词均已被否，仅供对照，不要再在其上修改。

## 1. 图层表

你给的两层框架是对的，落地时把上层再拆细一点，改稿才不会互相牵连。

| 层 | 名称 | 内容 | 制作工具 | 是否透明底 |
| --- | --- | --- | --- | --- |
| L3 | 文字层 Text | 主标题、英文短名、副标题／标语、底部信息行（团队／赛题／日期） | PPT 文本框 | 原生对象，不涉及 |
| L2 | 元素层 Vector | 中枢卡片、5 个圆形阶段图标、左上角数据卡、折线图、节点标签牌 | PPT 形状 + 原生图表 + 图标 | 原生对象，不涉及 |
| L1 | 装饰层 Alpha | 发光曲线、光柱、粒子网点、底部多层波浪、细线网格 | PPT 形状／SVG，或导出透明 PNG | 是（Alpha） |
| L0 | 背景层 Base Image | **「报告地层」**：半透明研报纸页层理、排版透印纹理、贯穿式证据索引细线、下方纯净留白（不再用城市航拍／地球／网络节点等通用模板元素） | 生图模型，**唯一位图** | 否，铺满整页 |

**关键分工**：L0 决定「气质」，L1–L3 决定「信息」。L0 一旦定稿就锁定，之后 90% 的改稿只动 L1–L3，不重新生图。

## 2. 画布与坐标锚点

用 16:9，设计坐标按 1280×720 记（对应 WPS 插入尺寸 33.85 cm × 19.05 cm；放映图可放大到 18000×10125）。百分比坐标便于任何分辨率复用。

| 区域 | 位置（相对整页） | 说明 |
| --- | --- | --- |
| 场景区 | y 0%–62% | L0 的纸页层理＋雾感＋索引细线；主体集中上部，不要下沉 |
| 标题留白区 | y 62%–100% | 必须完全纯净，不得有任何纸页、层理、线条、光点侵入 |
| 主标题组 | x 起 6%，y 70%–82% | 超大号深墨绿中文主标题 + 同行英文短名 |
| 副标题／标语 | x 起 6%，y 83%–88% | 一行，字号约为主标题 1/3 |
| 底部信息行 | x 起 6%，y 92%–95% | 赛题编号、团队、日期，14–16px |
| 波浪装饰 | y 88%–100%，右侧为主 | 多层低饱和青绿，不得越过 y 88% 侵入标题行 |
| 中枢卡片 | 水平居中，y 10%–24% | 半透明磨砂质感胶囊／圆角块 |
| 五个阶段节点 | 等距横排，y 30%–38% | 对应五阶段流水线 |
| 左上角数据卡 | x 3%–24%，y 10%–32% | 半透明白色卡，内含折线与一个数值 |
| 节点标签牌 | 散布 y 42%–62% | 深绿底白字小标签，指向中景节点 |

**参考封面的关系要保住**：中枢在上、向下放射虚线 → 一排圆形功能图标 → 再向下连到中景节点；地面有贯穿的青绿光带把左右串起来；左上独立一块数据卡；下方大面积留白承载标题；右下波浪收边。这套「自上而下的拓扑 + 左下大标题 + 右下轻装饰」就是版式气质本身。

## 3. 制作顺序（照这个做）

1. **定死画布与配色**：16:9，主色深墨绿 `#0F4C3A`／`#0F6E56`，辅助青绿 `#1D9E75`、薄荷 `#9FE1CB`，底色白／极淡青绿，正文深墨 `#292E30`。全篇只用这一套，不引入第二主色。
2. **生 L0 底图**：复制 `L0_底图生图提示词.txt` 全文到生图模型。验收三条：画面里有没有混入文字／数字／图标（有就重生成，不要靠修图擦）；下方 32% 是否真的干净；整体是否偏青绿、高明度、不刺眼。**通过后立刻锁定，存 `L0_base.png`，不再改。**
3. **铺底图**：在 PPT 里插入 `L0_base.png`，铺满整页、置于最底层、锁定纵横比（WPS 中 33.85 × 19.05 cm）。这一层之后不再动。
4. **搭 L1 装饰层**：用自由曲线画贯穿中景的青绿光带（半透明、带柔光边缘），画从中枢向下的放射虚线，画右下多层波浪。全部矢量，方便单独换色／换透明度。若用 PS／Figma 做，导出**透明底 PNG（保留 Alpha）**，不要压成白底 JPG。
5. **搭 L2 元素层**：中枢卡片、五个圆形线性图标（取数／解读／图表／章节／融合）、左上数据卡（用 PPT 原生图表画折线，数值用文本框填真实数字）、中景节点标签牌。图标统一线性、单色、同线宽，禁止彩色面性图标。
6. **搭 L3 文字层**：主标题、英文短名、副标题、底部信息行全部用文本框，字体建议思源黑体／微软雅黑 + Arial。**标题文字不要写进生图提示词，也不要让生图生成任何字。**
7. **交付两份**：一份**可编辑分层文件**（PPTX 原生对象，或 PSD 分层稿）用于改稿；一份**合并后的整页图**（PNG／PDF，16:9）用于放映与备份。命名建议 `cover_layered.pptx` / `cover_final.png`。

## 4. 结合本项目的内容替换表

不照搬参考封面的任何文字、标识、品牌、地标素材，只保留位置关系。

| 参考封面元素 | 本项目替换内容 |
| --- | --- |
| 中文主标题 + 英文产品名 | 自拟项目短名 + 英文短名（如体现「行业研报智能生成／多智能体」），**不要出现赛题方品牌与参考项目名** |
| 副标题 | 一句话点题：输入行业主题 → 输出可溯源研报／人机协同优化 |
| 云朵中枢卡片 | 五阶段流水线中枢（可写「编排中枢」类中性词），下方 4 个小标签改为能力词 |
| 一排圆形图标 | 取数、解读、图表、章节、融合（对应 A1–A5） |
| 各处地名标签牌 | 换成能力节点：证据穿透 `record_id`、人机协同审核、质量门禁、三格式交付、SkillHub 技能调用 |
| 左上折线图 + 百分比 | 换成**有真实来源**的项目指标（如离线回归通过数、样例报告页数），须带口径；没有把握就改为纯示意折线，不编数字 |
| 城市航拍／地标建筑 | 全部弃用，改为「报告地层」纸页层理——底图视觉必须来自研报本身，不用与报告无关的场景 |

> 项目红线：不编市场规模、客户数、渗透率、营收预测；封面出现的任何数字都要能说清来源与口径。

## 5. 验收清单

- [ ] 删掉 L0 底图后，L1–L3 在纯白底上仍完整可读（分层成立）
- [ ] 底图 100% 放大检查：无任何烧进图里的文字、数字、logo、图标、可读图表
- [ ] 底图概念检查：主体是研报纸页层理，没有城市／建筑／地球／节点网络／粒子光流等通用模板元素
- [ ] 标题区 y 62%–100% 完全纯净，无层理、线条、光点穿越，文字与底图对比度足够（深绿字压浅底）
- [ ] 改一个字只需改文本框，不用重新生图
- [ ] 所有透明素材是 Alpha PNG／矢量，不是白底 JPG
- [ ] 图标同风格、同线宽、同色；全页文字样式 ≤ 4 种
- [ ] 封面信息层级 ≤ 4 层（主标题／副标题／说明／底部信息），**封面不放数据看板或一排指标**
- [ ] 同时留存可编辑分层稿与合并整页图；放映前用投影／全屏预览检查一次

## 6. 常见坑

1. **把元素层导出成白底 JPG**：叠上去会盖住底图，出现方块。必须保留 Alpha 或直接用 PPT 原生形状。
2. **想让生图「顺便」把标题写好看**：生图对中文精确文字基本不可控，一定糊／错字。文字只走文本框。
3. **折线图交给生图**：数值、坐标轴、图例全不可信。用 PPT 原生图表或 SVG 手绘，数值来自真实产物。
4. **底图没锁就反复重生成**：每次重生成光效位置都变，所有标签要重新对位。L0 定稿即冻结。
5. **把 18K 大图当可编辑稿**：18K 只是放映用的分辨率，不是分层文件；改稿必须回到 PPTX／PSD。

## 7. 术语对照（便于和设计／同学沟通）

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 分层合成 | Layered Composition / Compositing | 把画面拆成独立图层再叠加 |
| 图层 | Layer | 每层可单独编辑、隐藏、替换 |
| 背景层／底图 | Background Layer / Base Image | 唯一位图，只定氛围 |
| 前景层／矢量浮层 | Foreground / Overlay Layer | 文字、形状、图表，全部矢量 |
| 图文分层 | Text–image separation | 文字与照片分离，便于改字 |
| 分层文件 | Layered source file | PSD 分层、可编辑 PPTX |
| 透明底素材 | Alpha asset | PNG Alpha 通道，透明区不遮底图 |
