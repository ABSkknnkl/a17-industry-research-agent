# 智研天工 · 行业研报智能生成与人机协同系统

基于同花顺问财 SkillHub 的行业研究报告智能生成系统。输入主题、样本与截止日，系统按五阶段流水线完成取数、解读、制图、分章写作与报告融合，关键节点由研究员审核，最终交付 Markdown / HTML / PDF 三种格式，并附证据目录与审计记录。

## 核心主张

**报告不是一次性生成的文本，而是可审计的装配过程。** 每条关键数字带证据编号、可回查到原始披露；每类错误有门禁拦截；每个阶段可暂停、审核、局部重跑。

## 架构

- **L1 交互层**：任务工作台、五阶段审核台、报告预览
- **L2 编排层**：FastAPI、八态状态机、run_id 与 revision 并发控制
- **L3 智能体层**：Agent1 取数 → Agent2 解读 → Agent3 制图 → Agent4 分章 → Agent5 融合
- **L4 能力层**：问财 SkillHub（66 项技能）、模型、文件与证据存储

阶段之间只交接带 schema 校验的结构化产物；证据编号贯穿五阶段（record_id → point_evidence_ids → evidence_ids → evidence_catalog）。

## 四个判定算法

| 算法 | 解决的问题 | 一句话实现 |
|---|---|---|
| DPE 精度判等 | 同一数字不同披露精度被误判冲突 | 从披露串反推步长，精细侧按粗侧舍入后比较 |
| 稳健 Z | 错数不报错、混入成稿 | 中位数 + MAD，阈值 3.5，只标注不删数 |
| CLA 断言核验 | 句子专业但依据是编的 | 六类断言各配证据标准，保序幂等裁剪 |
| RPD 拓扑修复 | 产业链图乱、查出错却修不好 | 七条硬约束 + 按关系权重删边，报错集 ⊆ 可修集 |

## 实测

- 完整报告：7 章 21 节、15 张图、348 条证据、25 页 PDF、3 种格式
- 端到端耗时：十几到二十分钟（取数约 50 秒、21 节并发约 7 分钟、融合约 30 秒）
- 五问轻量版：180 秒、33 次模型调用、24 页 PDF
- 断言核验：拦截 81.0%、误删 5.6%

## 快速开始

```bash
cd a17-industry-research-agent
cp .env.example .env            # 填入模型与问财凭证
pip install -r requirements.txt
python3 backend/run_server.py   # API :8000
cd frontend && npm install && npm run dev   # UI :5173
```

或使用 `./start_system.sh` 同时启动前后端。

## 边界

系统是研报初稿与底稿生成器，不输出投资建议、不设目标价与买卖评级；行业规则目前为五行业人工配置；多用户鉴权与数据商用授权尚未接入。详见《开发总结》第 4 节。
