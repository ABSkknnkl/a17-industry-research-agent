# 行业研究智能体 — 前端界面（纯净空壳）

本项目为**纯前端界面空壳**，已彻底移除所有硬编码 Mock 数据与离线原型仿真逻辑，纯粹通过 HTTP API（`/api/v1`）与后端行业研究智能体服务进行交互。

---

## ⚡️ 快速开始

### 1. 启动本地开发服务

```bash
cd frontend
npm run dev
```

启动成功后，浏览器打开：
👉 **http://localhost:5173/**

### 2. 后端接口连接配置

前端默认通过 Vite 反向代理请求本地后端服务。
如需自定义后端服务地址，可创建或编辑 `.env.local` 文件：

```env
# 后端服务接口地址（默认代理到 http://localhost:8000）
VITE_API_BASE_URL=http://localhost:8000
```

## 📁 页面与组件指引

### 视图目录 (`src/views/`)：

- **`src/views/HomeView.vue`**：研报主题输入、市场范围、证券类型与启动流水线任务界面
- **`src/views/ReviewView.vue`**：核心三栏人机审核工作台（流水线进度、证据链、ECharts 图表画廊、正文草稿、风险处置决策）
- **`src/views/RunsView.vue`**：历史研报任务与批次看板
- **`src/views/ReportPreviewView.vue`**：最终研报全屏阅读与排版预览
- **`src/views/ReportDownloadView.vue`**：研报多格式产物下载中心（Markdown、HTML、PDF 及产物清单）

### 核心组件 (`src/components/`)：

- **`src/components/StageStepper.vue`**：五阶段流水线进度导航
- **`src/components/StageDigest.vue`**：阶段数据与审核摘要信息展示
- **`src/components/ChartGallery.vue`**：ECharts 研报图表画廊与交互组件
- **`src/components/ReviewActions.vue`**：审核决策条（通过、修改条件重跑、驳回、原条件重新生成）
- **`src/components/WorkbenchActions.vue`**：工作台动作栏（重新融合、修改指令提交）
- **`src/components/ReportReader.vue`**：研报内容富文本渲染器
- **`src/components/PipelineOverlay.vue`**：流水线执行与加载状态遮罩

## 🛠️ 项目构建与验证命令

- `npm run dev`：启动本地开发调试服务器
- `npm run build`：执行 TypeScript 检查并构建生产包到 `dist/`
- `npm run type-check`：Vue 与 TypeScript 强类型校验
- `npm run lint`：ESLint 代码规范与规则检查
- `npm test`：运行 Vitest 单元测试
- `npm run verify`：一键执行类型、规范、格式与单元测试全套验证

---

## 📦 生产部署

执行 `npm run build` 后，打包静态文件位于 **`dist/`** 目录。
可直接将其部署至 Nginx、Caddy 或任意静态资源托管服务器，并配置 `/api/` 代理指向 Python 智能体服务。
