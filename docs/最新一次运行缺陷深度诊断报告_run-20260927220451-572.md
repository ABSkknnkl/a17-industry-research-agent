#### 2. 代码根因定位
定位至 [`agents_core/chart-generator/chart_generator/agent.py#L1664-L1670`](file:///Users/panheng/Desktop/同花顺赛题/a17-industry-research-agent-agent-chart-mvp-sync/agents_core/chart-generator/chart_generator/agent.py#L1664-L1670)：
```python
for y, (metric, rows) in enumerate(matrix_metrics):
    values = [float(rows[e].value) for e in entities]
    low, high = min(values), max(values)
    span = high - low or 1
    for x, (entity, value) in enumerate(zip(entities, values, strict=True)):
        cells.append([x, y, round((value - low) / span * 100, 2)])
```
- 代码采用了极其原始的线性 Min-Max 缩放：`span = 996.6 - (-1026.4) = 2023.0`。
- 对于正常龙头公司（市盈率在 15~25 倍之间）：
  $$\text{Score} = \frac{20 - (-1026.4)}{2023.0} \times 100 = \frac{1046.4}{2023.0} \times 100 \approx 51.72 \to \dots \approx 68.7 \dots$$
- 8 家公司的得分在 68.5 到 69.1 之间，再经过 `render.py#L1373` 的整数四舍五入 `{val:.0f}`，**全员强制变成 69**！

#### 3. 生产级修复方案 (Code Diff)
金融热力图行业通用做法：**采用分位数排序（Percentile Rank）或缩尾均值化（Winsorized Min-Max）**：
```python
# agents_core/chart-generator/chart_generator/agent.py
# 采用百分位分位排序归一化，彻底免疫单点极端值破坏
sorted_vals = sorted(values)
n_vals = len(sorted_vals)
for x, (entity, value) in enumerate(zip(entities, values, strict=True)):
    # 计算经验分位百分比 (0 ~ 100)
    rank = sorted_vals.index(value)
    pct_score = round(rank / max(n_vals - 1, 1) * 100, 1)
    cells.append([x, y, pct_score])
```
改用分位数后，10 家企业的动态市盈率得分将均匀离散为 `0, 11, 22, 33, 44, 56, 67, 78, 89, 100`，热力阶梯与颜色渐变完美展现。

### 【NEW-09】P2 级：A 股股票价格横向比较柱状图提示“原始数据未提供统一单位”

#### 1. 现象与证据
在《图 9：最新股价横向比较》（`CHART-02-BDE012C2`）底部，出现如下注记：
*“注：原始数据未提供统一单位，跨实体比较需谨慎”*。
A 股股票价格的法定交易单位全部为“人民币元/股”，这一通用常识提示暴露出系统内部逻辑对股价单位的推导断裂。

#### 2. 代码根因定位与修复
在 [`agents_core/chart-generator/chart_generator/agent.py#L1446`](file:///Users/panheng/Desktop/同花顺赛题/a17-industry-research-agent-agent-chart-mvp-sync/agents_core/chart-generator/chart_generator/agent.py#L1446)：
```python
footnotes = [] if unit else ["原始数据未提供统一单位，跨实体比较需谨慎"]
```
问财返回的 `latest_price` 指标的 `unit` 字段为 `null`，导致 `unit` 为空字符串。代码简单以 `if not unit` 触发了该警示注释。
**修复方案**：
对 `latest_price`、`close`、`price` 等股票价格类指标，默认单位固化为 `"元"` 或 `"元/股"`，禁止触发此类注记。
