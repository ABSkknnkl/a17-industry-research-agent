## 4. 关键设计决定

| 决定 | 为什么 | 代价 |
|---|---|---|
| **模板双模式**：`render_layout_html`（母本骨架）与 `render_from_ast`（AST 生成） | 冻结夹具必须逐页对照母本，而真实 `ReportViewModel` 没有母本 HTML，两者输入源不同 | 两套渲染路径，需保证共用 CSS/目录/图 8 逻辑 |
| **编号双轨**：`numbering_mode=preserve_mother / reading_order` | 母本表号是 `表4/表1/表2/表3/表5/表A1/表A2`（语义编号），按阅读顺序重编会与母本全错位 | 注册表多一个字段；生产新报告仍可连续编号 |
| **compose 一次产出同批 HTML/PDF/页映射** | 方案要求「HTML 中的页码指向同批 PDF」；Chromium 回填页码只改浏览器 DOM | PDF 生成后必须回写 `report.html`，`agent.py`/`state_machine.py` 各加一个分支 |
| **页眉页脚单一策略：PyMuPDF 盖章** | Chromium 页脚无法跳过封面 | 关闭 Chromium header/footer；中文用 `china-s` |
| **表 A2 汇总来源由注册表生成** | 母本该表只有「注」，手写一句来源等于伪造 | 必须先跑逐行绑定；缺口单列，不硬凑 |
| **A3 资产按内部 run_id 递归发现** | 目录名 ≠ run_id，`a3_live_direct/` 这类嵌套验收目录会被漏掉 | 扫 70 个 `chart_result.json`，耗时约 1s |
| **封面简化为「版式主题 + 交付状态」** | 真实 A2 没有封面字段（主标题/hero 数值/报告信息） | 真实稿封面信息少于母本样例 |

### 5.4 常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| `未配置模型 API Key` | shell 未注入，脚本只从 `.env` 读 `LLM_*` | 确认 `.env` 存在且 key 未过期 |
| `PDF 目录目标缺少可解析页码` | 目录条目引用了不存在的锚点 | 检查 `render_toc_page` 的 key 与正文 `id` 是否一一对应 |
| `PDF 目录分页未能稳定` | 页码回填导致重排，5 轮未收敛 | 检查目录是否超一页；方案要求此时走 `toc_overflow` 策略 |
| `排版门禁未通过` | `compose` 的 page_map 不一致 | 看 `layout_manifest.json` 的 diagnostics |
| P0 门禁 FAIL | 母本或 A3 产物被改动 | 对比 `freeze_manifest.json` 的 SHA-256 |

## 8. 踩过的坑（根因 → 现象 → 修法）

| # | 根因 | 现象 | 修法 |
|---|---|---|---|
| 1 | 只按同名 run 目录找 A3 产物 | 误判「产物不存在」，P3 provenance 全降级 | 递归扫 `output/**/chart_result.json`，按内部 `run_id` 匹配 |
| 2 | 扁平正则解析 CSS | `@media print{body{...}}` 覆盖 `body{font-size}`，主题字号丢失 | 括号配对递归解析，@media 规则单独归类 |
| 3 | `div.conclusion` 被按块切碎 | 结论文本进不了 AST，结论 diff 是空集 | 按 div 深度配对整体成块 |
| 4 | `EVIDENCE_ID_RE` 只认 `R-/CHART-` | 母本证据是脚注 `[1]`，证据 ID diff 空集 | 正则补 `\[[1-9]\d?\]`，并逐条生成 `cite` 块 |
| 5 | 富文本白名单把结构标签当未知 | 252 条假告警（figure/img/caption/h2） | 结构化块走专门解析；白名单覆盖模板全部已知标签，未知标签仍报警 |
| 6 | 注册表按阅读顺序重编号 | 母本 `表4/表1/表2…` 被改成 `表1…表7`，与母本全错位 | 加 `numbering_mode`，夹具用 `preserve_mother` |
| 7 | 图 8 把母本题注与 A3 全景哈希挂同一条目 | 题注说「只比中游电池与下游整车」，图却含上游 | provenance 拆 `mother_asset` / `asset_path`，图题更新，母本原题存 `data-mother-title` |
| 8 | `.conclusion` 是 `12mm + 1fr` 两列网格 | 只输出一个子元素，正文被挤成竖排 | 补齐编号列 + 正文列 |
| 9 | 无图表时仍渲染图表目录 | 目录页留空表头 | 无条目则不渲染该段 |
| 10 | 结构化附录 dict 当 HTML 输出 | 打印出 `{'requirement_output_links': []}` | raw 块按转义文本输出 |
| 11 | 目录副标题用默认值 | 真实稿 7 章却写「共 5 章 · 8 图 · 7 表」 | 按本稿章/图/表实时统计 |
| 12 | 执行摘要 heading 用整段 headline | 目录出现 60 字长标题 | 标题固定「执行摘要」，headline 降为导语 |
| 13 | 章末最后一块溢出到新页 | p09 只有一行「非外推声明」独占整页 | 章末最后两块加 `break-before:avoid` |
