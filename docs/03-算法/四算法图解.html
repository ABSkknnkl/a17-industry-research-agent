01 / DPE4.1 · 精度判等

两个数，是不是同一个数？

不判谁对谁错，只判要不要把它们当成吵架。

16.2 报到 0.1，覆盖 16.15—16.25 16.17 落在里面 → 同一个数 16.25 正好出界，进位成 16.3

精度从原始披露串里读，不设百分比容差；细的向粗的舍入，方向不可反。

它不管：这个数本身对不对。原始串丢了，只能降置信度。

1.2 亿元 = 12,000 万元 ✓ 先换单位，步长一起换
02 / 稳健 Z4.1 · 异常筛查

谁站得离队伍太远？

五到十家公司里，一个极端值就能把平均值带偏。

中心 = 中位数，不怕极端值 尺子 = MAD，典型偏离 分数 = 0.6745 × 偏离 ÷ MAD

同组至少 5 个样本、MAD 大于 0；阈值 3.5，两倍记高。只标候选。

它不管：这家公司是不是真的经营恶化。口径不同也会造成大偏离。

23% vs 中位数 19%、MAD 1.2% → Z = 2.25，不标
03 / CLA4.2 · 断言核验

一句话里，哪半句能留？

整段删可惜，整段留危险；所以要切到半句。

营收同比增长 29%，主要因为电池成本下降，行业第一，若碳酸锂涨价则毛利回落。

保留营收同比增长 29%　能反算：7,771 与 6,023 算出 29.0%
删除主要因为电池成本下降　因果：原文没有这句话
删除行业第一　排名：没说在哪个样本里比
限本句若碳酸锂涨价则毛利回落　假设：不得拿去支撑别的句子
裁后：只删不增，顺序不变营收同比增长 29%。若碳酸锂涨价则毛利回落。
六类：数值 / 方向 / 因果 / 排名 / 预测 / 情景 每类各配一种证据标准 判不了 → 拦

数值能反算，方向只能靠序列，因果只能原文直引或标假设，排名必须有边界。

它不管：这句话真假。上游证据错了（比如单位差 100 倍），它救不了。

同一段裁两次，结果逐字相同（幂等）
04 / RPD4.2 · 拓扑修复

图上的错，判得出也要修得好

模型说“是什么”，代码说“对不对”，修完留痕。

核心 16 中游非核心 12 其他 8 判据 校验与修复共用

删边顺序：回收 0 ＜ 服务 1 ＜ 技术 2 ＜ 实物流 3。先删弱关系，最后才动主链。

它不管：不追求全局最优。这是保主链的加权贪心，可解释比最优更重要。

答辩时，一句话怎么讲

算法可以这么说不要这么说
DPE精度不是参数，是数据属性：从披露串读出报到第几位，再单向舍入判等。“就是四舍五入加个阈值”
稳健 Z用小样本抗污染的中位数和 MAD 找候选，只提示、不下结论。“Z 高就说明经营恶化”
CLA先给断言定类型，再给每类配证据标准；判不了就拦，裁完可重复。“我们做了事实核查”
RPD裁判和修理工共用一套判据，判得出的错必须修得好。“我们求了全局最优”
