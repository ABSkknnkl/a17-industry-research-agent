# 前端未接入后端接口的组件清单

- 日期：2026-09-17
- 范围：`frontend/src/` 全部 Vue 组件与视图
- 判定标准：组件中存在**仅在 mock 模式下可用**的功能（`v-if="mockMode"` 或 `disabled="!mockMode"`），或**直接依赖 `usePrototypeStore`** 而无真实 API 替代路径

---

## 一、架构背景

前端采用**双模式架构**：

| 模式 | 判定 | 数据来源 |
|---|---|---|
| 真实模式 | `isMockDataMode() === false` | `api/client.ts` → 后端 REST API |
| 演示模式 | `isMockDataMode() === true` | `mock/prototypeRun.ts`（Pinia store，localStorage 持久化） |

**后端现有 API 端点（8 个）**：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/ping` | 健康检查 |
| POST | `/runs` | 创建任务 |
| GET | `/runs` | 任务列表 |
| GET | `/runs/{id}` | 任务详情 |
| GET | `/runs/{id}/revisions` | 版本列表 |
| GET | `/runs/{id}/revisions/{rev}` | 版本详情 |
| GET | `/runs/{id}/artifacts/{aid}` | 下载产物 |
| POST | `/runs/{id}/reviews` | 提交审核（approve/revise/regenerate/cancel） |

**Mock store 额外支持但后端没有的操作（11 个）**：

| 操作 | 说明 |
|---|---|
| `startSimulation` | 模拟流水线逐步推进 |
| `selectStage` | 切换当前查看的阶段 |
| `rejectClaim` / `restoreClaim` | 驳回/恢复单条 claim |
| `updateChartTitle` | 修改图表标题 |
| `deleteChart` | 删除单张图表 |
| `retryChart` | 重试图表生成 |
| `regenerateChapter` | 按指令重新生成章节 |
| `deleteChapter` | 删除章节 |
| `acknowledgeRisk` | 确认风险项 |

## 三、汇总：需后端新增的接口

| 优先级 | 接口 | 对应智能体 | 前端功能 | 涉及组件 |
|---|---|---|---|---|
| **P0** | `GET /runs/{id}/evidence` | **Agent 2 数据解读** | 证据列表展示 | EvidenceReviewTable |
| **P0** | `POST /runs/{id}/claims/{cid}/reject` | **Agent 2 数据解读** | 驳回单条 claim | ClaimReviewList |
| **P0** | `POST /runs/{id}/claims/{cid}/restore` | **Agent 2 数据解读** | 恢复单条 claim | ClaimReviewList |
| **P1** | `PATCH /runs/{id}/charts/{cid}` | **Agent 3 图表生成** | 修改图表标题 | ChartControlMenu |
| **P1** | `DELETE /runs/{id}/charts/{cid}` | **Agent 3 图表生成** | 删除图表 | ChartControlMenu, StageDigest |
| **P1** | `POST /runs/{id}/charts/{cid}/retry` | **Agent 3 图表生成** | 重试图表 | ChartControlMenu |
| **P1** | `POST /runs/{id}/chapters/{cid}/regenerate` | **Agent 4 章节写作** | 重生成章节 | StageDigest |
| **P1** | `DELETE /runs/{id}/chapters/{cid}` | **Agent 4 章节写作** | 删除章节 | StageDigest |
| **P2** | `GET /runs/{id}/revisions/{a}/diff/{b}` | **Workflow 工作流** | 版本对比 | RevisionDiffDialog |
| **P2** | `POST /runs/{id}/risks/{code}/acknowledge` | **Agent 5 报告融合** | 确认风险项 | ReviewActions |
| **P2** | ChartSpec 扩展字段 | **Agent 3 图表生成** | 状态徽章/版本号/来源 | ChartGallery |

## 四、一句话总结

**6 个组件存在 mock-only 功能**，核心缺口按智能体分布：

| 智能体 | 缺口 | 优先级 |
|---|---|---|
| **Agent 2 数据解读** | 证据查询、claim 级驳回/恢复 | P0 |
| **Agent 3 图表生成** | 图表 CRUD、重试、状态字段 | P1 |
| **Agent 4 章节写作** | 章节删除、按指令重生成 | P1 |
| **Agent 5 报告融合** | 风险确认 | P2 |
| **Workflow 工作流** | 版本 diff | P2 |

**Agent 1 数据获取**无缺口——前端不直接调用 Agent 1，数据通过 `getRun` 响应透传。
