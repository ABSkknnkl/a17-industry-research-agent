## 一、系统定义与运行环境要求

### 1. 系统定义
A17 行业研究报告智能生成与人机协同优化系统是面向证券投研场景的现代化工业级软件。系统深度对接同花顺问财 SkillHub 金融技能生态，采用五阶段流水线解耦的多智能体架构（获取、解读、图表、章节、融合），并配套提供全生命周期人机协同工作台（Vue 3 + ECharts），支持 Markdown、交互式 HTML 及出版级矢量分页 PDF 研报的自动化与协同出具。

### 2. 软硬件运行环境推荐
- **操作系统**：Linux (Ubuntu 22.04 LTS+ / Debian 12 / CentOS Stream 9)、macOS (Apple Silicon M系列 / Intel x86_64)、Windows 11 (建议通过 WSL2 运行)；
- **Python 运行时**：Python 3.10.x 或 3.11.x（建议使用 `venv` 或 `conda` 隔离环境）；
- **Node.js 运行时**：Node.js 18.x LTS 或更高版本（npm 9.x+ 或 pnpm 8.x+）；
- **硬件配置建议**：
  - CPU：4 核以上（推荐 8 核）；
  - 内存（RAM）：推荐 16GB 以上（最低 8GB）；
  - 磁盘空间：至少保留 10GB 可用空间（用于缓存中间件数据、图表资源与 PDF 渲染缓存）。

## 二、快速部署与启动指引

### 1. 代码准备与依赖安装

```bash
# 1. 切换至项目主目录
cd /Users/panheng/Desktop/同花顺赛题/a17-industry-research-agent

# 2. 创建并激活 Python 虚拟环境 (以 venv 为例)
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 安装后端核心依赖
pip install --upgrade pip
pip install -r requirements.txt

# 4. （可选但推荐）安装 Playwright 浏览器内核以支持矢量分页 PDF 导出
playwright install chromium

# 5. 安装前端依赖
cd frontend
npm install
cd ..
```

### 2. 模型服务商与同花顺问财凭据配置（两种方式）

#### 方式 A：前端可视化配置面板（推荐，零门槛）
1. 启动服务后打开前端（默认 `http://localhost:5173`）；
2. 点击右上角 **「模型与接口配置」** 按钮；
3. 选择您使用的服务商预设（DeepSeek、火山引擎方舟、硅基流动、OpenAI 或 本地 Ollama）；
4. 输入 `大模型 API Key` 与 `同花顺问财凭证 (IWENCAI_TOKEN)`；
5. 点击 **「测试连通性」**，确认指示灯变绿后点击 **「保存并应用」**，后端即刻热更新生效。

#### 方式 B：本地 `.env` 文件配置（适合生产/服务器环境）
复制根目录模板并编辑 `.env`：
```ini
# 大模型服务配置
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-your-llm-api-key-here
LLM_MODEL=deepseek-chat
LLM_TEMPERATURE=0.2

# 同花顺问财 SkillHub 接口配置
IWENCAI_API_BASE=https://www.iwencai.com/unifiedwap/skillhub
IWENCAI_TOKEN=your_iwencai_token_here

# 系统与存储配置
PORT=8000
DATA_DIR=data/runs
MAX_CONCURRENT_CHAPTERS=7
```

### 3. 一键全栈启动

系统内置了现代化的一键启动脚本：
```bash
./start_system.sh
```
该脚本将自动完成：
1. 端口健康检查（避免 8000 / 5173 冲突）；
2. 启动 FastAPI 后端服务并循环探测 `/health` 端点直到健康；
3. 启动 Vite 前端服务；
4. 终端按 `Ctrl+C` 可一键安全平滑退出前后端所有子进程。

*(注：如需独立调试，可分别运行 `python3 backend/run_server.py` 与 `cd frontend && npm run dev`)*

## 四、核心智能体模块与接口规格说明

### 1. 后端 RESTful API 核心端点规格

| HTTP 方法 | 端点路径 | 功能描述 | 核心输入 / 输出说明 |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/runs` | 创建新研究任务 | 输入 `RunCreateRequest`（行业、市场范围、关注点、协同模式），返回 `run_id` |
| `GET` | `/api/runs/{run_id}` | 获取任务实时状态 | 返回 `WorkflowState`（包含当前阶段、状态、各阶段成果与快照） |
| `GET` | `/api/runs/{run_id}/events` | SSE 实时事件流 | 流式推送 `AgentTraceEvent`（智能体思考、工具调用、完成事件） |
| `POST` | `/api/runs/{run_id}/review` | 提交人机协同审核干预 | 输入 `ReviewRequest`（动作：`approve` / `revise` / `customize` 等），驱动状态机流转 |
| `GET` | `/api/runs/{run_id}/artifacts/{name}` | 下载指定阶段产物 | 获取 `dataset.json`、`report.md`、`report.html`、`report.pdf` 等物理文件 |
| `GET` | `/api/skills` | 获取问财 SkillHub 目录 | 返回系统已注册的官方与扩展技能包元数据列表 |
| `POST` | `/api/settings/config` | 动态热更新配置 | 热更新 API Key、模型基座地址与并发参数，无需重启后端 |

### 2. 状态机生命周期模型 (`StageStatus`)
各阶段遵循以下严格状态转移序列：
- `pending`：未开始，等待前置依赖就绪；
- `running`：智能体执行中，向前端流式传输思考事件；
- `waiting_review`：阶段执行完成，**挂起暂停**，等待分析师人工审核确认；
- `approved`：人工审批通过，状态机自动唤醒并激活下一阶段；
- `completed`：全流程 5 阶段执行完毕，研报正式签发；
- `failed`：异常失败，系统保留现场快照并支持自愈重跑。

## 五、全流程业务操作指南（含人机协同工作台）

### 步骤 1：创建行业投研任务
1. 打开系统主页（`http://localhost:5173`），点击 **「发起研究」**；
2. 输入 **研究行业**（例如：“商业航天”、“低空经济”或“动力电池”）；
3. 选择 **市场范围**（支持中国 A 股、港股、美股多选）与 **报告币种**；
4. 输入 **核心关注问题**（例如：“上中下游竞争格局与主要壁垒”、“核心标的近三年研发费用率与毛利率对比”）；
5. 选择 **协作模式**：
   - **分步协同模式（推荐）**：系统在 5 个阶段均提供审核介入卡口；
   - **全自动模式**：系统无停顿一键直达最终研报。

---

### 步骤 2：阶段 1 数据获取人机协同
- **界面展现**：系统抓取完成后进入 `waiting_review`，工作台左侧展示抓取覆盖领域（宏观、行业、财务、行情、资讯等）与捕获的 100+ 条数据卡片；
- **协同操作**：
  - 若数据满意：点击右上角 **「批准流转 (Approve)」**；
  - 若需要补充检索：点击 **「修改关键词/范围」**，输入增补词后点击提交，系统仅对增量部分重新调用问财；
  - 若缺少核心财务：点击 **「发起增量补采」**，输入需补充的目标企业与财务科目。

---

### 步骤 3：阶段 2 数据解读人机协同
- **界面展现**：中栏展示确定性量化指标卡片（CAGR 增速、估值分位、稳健 Z-score 离群值）与 20 项方法论提炼的关键洞察；
- **协同操作**：
  - 研究员可在 **「专家背景知识注入」** 输入框中写入特定的定性洞察（例如：“行业受国家商业航天专项支持政策加速”）；
  - 注入的专家背景将自动固化并渗透至后续章节撰写智能体的提示词上下文中。

---

### 步骤 4：阶段 3 图表生成人机协同
- **界面展现**：ECharts 画廊网格化排列生成的 6~17 幅出版级图表，支持全屏放大查看数据点与缩放；
- **协同操作**：
  - **图表形态一键转换（Morph）**：例如点击“切换图表形态”，可将某分组柱状图即时转化为“水平对比条形图”或“堆叠面积图”，本地毫秒级重新编译渲染；
  - **图表增补诉求**：输入“加个市场份额饼图”，系统将调度编译模块补充对应图表资产。

---

### 步骤 5：阶段 4 章节撰写人机协同
- **界面展现**：展示 7 章 21 节树状大纲导航，右侧呈现各小节正文、定量对比表格与数据溯源角标；
- **协同操作**：
  - **单章节定向重写**：点击任意小节（如 `CH-01 行业定义与研究基础`），输入修改批注（如：“增加下行风险论述与估值安全边际”）；
  - 系统仅对选定章节重新调用大模型润色，保持其余 20 个章节不变，并在前端以红绿高亮呈现 **Revision Diff 差异比对**。

---

### 步骤 6：阶段 5 终审融合与研报导出
- **界面展现**：全篇报告渲染预览，呈现顶部的 Executive Summary 核心看板与文末数据溯源附录；
- **协同操作**：
  - 点击 **「批准发布」** 完成正式签发；
  - 点击 **「下载中心」**：
    - 导出 **Markdown 源码 (`.md`)**：方便在 Typora / 语雀等平台二次编辑；
    - 导出 **交互式网页 (`.html`)**：完整保留图表动态 tooltip 与缩放功能；
    - 导出 **出版级矢量 PDF (`.pdf`)**：由 Chromium 渲染，带精准印刷级分页、两遍目录与防伪页眉页脚。

## 六、配置文件与关键参数调优说明

配置文件路径：`backend/app/core/config.py` 与 `.env`

| 配置项键名 | 默认值 | 参数作用与调优建议 |
| :--- | :--- | :--- |
| `MAX_CONCURRENT_CHAPTERS` | `7` | 章节撰写并发数。显存或 API 并发限流较低时可调至 `3`；企业级并发时可设为 `7` 实现全并发 |
| `IWENCAI_TIMEOUT_SECONDS` | `30` | 问财 SkillHub 单次查询超时时间。网络波动较大时建议增加至 `45` |
| `DATA_QUALITY_TOLERANCE` | `0.01` | 多源财务数据交叉验证容差（默认 1%）。若跨数据源会计口径差异大，可微调至 `0.03` |
| `CHART_MAX_LIMIT` | `15` | 单篇报告允许生成的最大图表数量上限，防止图表过多导致篇幅臃肿 |

## 七、常见故障排查与技术支持（FAQ）

### Q1：启动时提示后端端口 8000 或前端端口 5173 被占用？
**解决办法**：
- 执行 `lsof -i :8000` 或 `lsof -i :5173` 查找占用进程 PID；
- 执行 `kill -9 <PID>` 释放端口后重新运行 `./start_system.sh`。

### Q2：生成 PDF 时提示 `Executable doesn't exist at ... chromium`？
**解决办法**：
- 系统缺少 Playwright 浏览器二进制包，在终端执行：
  ```bash
  playwright install chromium
  ```
- 重新在工作台点击导出 PDF 即可。

### Q3：问财 SkillHub 接口调用报错或提示 Token 失效？
**解决办法**：
- 进入前端右上角「模型与接口配置」，重新输入最新的 `IWENCAI_TOKEN` 并点击「测试问财连通性」；
- 若测试通过，点击保存即可即时生效，无需重启后端服务。

### Q4：大模型生成章节时提示超时（Read Timeout）？
**解决办法**：
- 检查大模型 API 余额与网络代理配置；
- 在 `.env` 中调大 `LLM_TIMEOUT=120`；
- 本系统具备局部重试保护，点击工作台对应的章节卡片即可单独触发重新生成。
