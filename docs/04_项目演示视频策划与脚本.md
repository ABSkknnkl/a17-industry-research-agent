```
[0:45 - 1:30] 系统架构全景     动态展示五阶段流水线解耦、FastAPI 状态机与实时协同工作台

[4:30 - 5:30] 成果检视与多格式导出 检视 90KB 万字 7章21节 研报长图、矢量分页 PDF、耗时缩减 90%
[5:30 - 6:00] 商业展望与致谢   总结赋能价值，致谢评审专家，升华主题
```

## 三、录制准备与素材清单

1. **环境准备**：
   - 本地启动后端：`python3 backend/run_server.py`
   - 本地启动前端：`cd frontend && npm run dev`
   - 确认测试数据与缓存已加载，避免网络抖动导致抓取等待过长；
2. **录屏软件设置**：
   - 软件推荐：OBS Studio 或 QuickTime（Mac 原生）；
   - 参数：1920×1080 分辨率，60 帧，码率 8000~12000 Kbps；
   - 隐藏桌面杂乱图标与通知，浏览器全屏（F11 / Control+Command+F），缩放调至 100%；
3. **后期剪辑要点**：
   - 鼠标点击操作处添加黄色光圈动效与轻微点击声；
   - 数据调用等待阶段可进行 2~4 倍速快进，并在屏幕右上角标注“后台并发计算中 (已加速 400%)”；
   - 关键功能标题使用统一的金融科技质感字幕条。
