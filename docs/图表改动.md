# 图表能力改动说明（简明版）

- 日期：2026-09-14
- 分支：`agent/chart-capability-code`
- 提交：`8bcdd76`（生产代码）+ `3b0445b`（说明文档）
- 本文件定位：用通俗语言说明**改了什么、有什么用、优化了什么**

---

## 一句话总结

**改之前**：AI 生成的图表能看数据，但不像研报——单位乱写、没有数字标注、重复图一堆、复合图画不出来、报告里没有图号目录。

**改之后**：图表达到券商研报可交付水平——有单位、有标签、有图号、有目录、有结论式标题、复合图能画了。

---

## 改了什么（按问题分组）

### 问题 1：坐标轴经常出现「CNY 未提供」

**原因**：数据缺单位时，系统把占位文字「未提供」直接拼进轴名。

**改法**：三层修复——
1. 建图时过滤掉「未提供」「文本」「不适用」这些占位词，不写进轴名
2. 占位词改成图注「[需核实:货币单位]」，读者能看到但不影响读图
3. 上游数据接口源头也做了归一，减少占位词产生

**效果**：87 张图里 26 张有此问题（30%），改后归零。

---

### 问题 2：同报告出现 6 张几乎一样的图

**原因**：去重时把「展示趋势」和「展示变化」当成不同目标，换个说法就能绕过去重。而且去重后系统故意不删重复图，只是标记一下。

**改法**：两步——
1. 先把同义词归到同一个槽位（趋势/变化/走势 → 都算 trend）
2. 再恢复删除逻辑：同 key 的图只保留第一张，其余直接砍掉

**效果**：同类图最多 6 张 → 最多 1 张。

---

### 问题 3：复合图（柱+线）画不出来

**原因**：系统规定「复合图必须两个不同单位」，结果「营收 + 净利润」这种都是亿元的最典型组合图，被强制降级成单线图。

**改法**：改成分支判断——
- 单位相同 → 单轴柱线（柱当背景，线压上面）
- 单位不同 → 双轴柱线（左右轴各自标注单位）
- 单位全空 → 拒绝出图（不瞎画）

**效果**：营收+净利润这类图不再被降级，一张图装两组数据，报告更紧凑。

---

### 问题 4：图表上没有数字，读者要自己估

**改法**：数据点 ≤12 个时自动加数值标签，>12 个不加（避免拥挤）。

---

### 问题 5：纵轴不从 0 开始但没有任何提示

**改法**：检测到纵轴截断时，自动在图注加一句「纵轴未从 0 开始」。

---

### 问题 6：图表没有关键点标注

**改法**：支持三种标注——
- **目标线**：虚线横线，如「目标价 8.0」
- **事件区间**：半透明阴影区，如「政策窗口期 6–8 月」
- **标注点**：图钉标记，如「年内低点」

---

### 问题 7：配色没有金融语义

**改法**：
- 涨跌类指标（名称含「涨跌/同比/增速」等）自动启用**红涨绿跌**
- 正值标红、负值标绿（A 股惯例）

---

### 问题 8：图表风格不像券商研报

**改法**：新增 `broker_thin` 主题——
- 无网格线
- 线宽 1.5px（细线密点时序风格）
- 无数据点圆圈
- 深海军蓝配色

---

### 问题 9：只能画一张图，不能左右并排

**改法**：新增 `dual_panel` 双图布局——
- 左图：绝对量（销量/产量）
- 右图：相对率/价格指数
- 共享时间轴，序列互不交叉

---

### 问题 10：数量阈值有 5 处各说各话

**改法**：全部收敛到一个 `constants.py` 文件，改一处全生效。

---

### 问题 11：报告里没有图表目录，编号会跳号

**改法**：
- 自动生成「图表目录」章节（图号 + 标题 + 所属章节）
- 用两遍编号法：先按渲染顺序排，再统一编号，保证目录和正文一致

---

### 问题 12：资料来源只显示 [1][2]，不知道是谁

**改法**：改成具名来源（「据弗若斯特沙利文」而非编号）。

---

### 问题 13：网页好看、PDF 难看（双渲染不同步）

**原因**：前端用 ECharts 画，报告用 SVG 另画一套，视觉参数没打通。

**改法**：SVG 侧同步实现了所有新特性——标签、截断提示、涨跌点色、双图布局、标注。防止「前端好看、报告没变」。

---

### 问题 14：标题不承载结论

**改法**：加校验规则——标题里没有数字或比较词（增长/下降/领先等）就标记 `title_not_conclusive`，提示改写。

---

### 问题 15：生成过程不可追溯

**改法**：每次生成/抑制都写一条审计日志（7 字段 JSONL），失败项单独落盘。

---

### 问题 16：数据不完整也硬画图

**改法**：画图前做数据体检——缺失率 >20%、类型不一致、字段不足 → 拦截不画。

---

## 改了哪些文件

| 文件 | 改了什么 |
|---|---|
| `constants.py` | **新建**，全仓唯一阈值来源 |
| `audit.py` | **新建**，操作审计日志 |
| `builders.py` | 核心：单位过滤、标签、标注、涨跌配色、broker_thin、双图、combo 分支 |
| `router.py` | combo 量纲分支、去重语义归一 |
| `quality.py` | 标题校验、对比度检查、数据体检、自查清单 |
| `service.py` | 去重抑制恢复、常量收敛、审计、失败落盘 |
| `schemas/chart.py` | 序列数 2→4、新增 Panel 和 Annotation 契约 |
| `svg.py` | 双面渲染同步（标签/点色/布局/标注） |
| `html.py` | 图表目录、连续编号 |
| `report_fusion/*` | 具名来源、阈值引用 |
| `data_fetcher/fusion.py` | unit 源头归一 |

## 量化效果

| 指标 | 改前 | 改后 |
|---|---|---|
| Y 轴含「未提供」 | 30% | **0** |
| 数据标签 | 0% | ≤12 点自动有 |
| 同类图重复 | 最多 6 张 | **≤1 张** |
| 同量纲复合图 | 被降级为单线 | **正常出图** |
| 图表目录 | 无 | **有** |
| 编号 | 跳号 | **连续** |
| 资料来源 | 编号 | **具名** |
| 券商风主题 | 无 | **有** |
| 左右双图 | 无 | **有** |

## 明确不做（作用域边界）

| 项 | 原因 |
|---|---|
| 新增图型（3D/地图） | 超出方案范围 |
| 平滑曲线 smooth | 券商研报时序图用直线 |
| Agent2 标题生成侧提示词 | 概率性 LLM 行为，延后单独立项 |
| 跨阶段断点续跑 | 触 workflow 编排，中风险，延后 |
| 换渲染库 | 仍用 ECharts option + SVG |
