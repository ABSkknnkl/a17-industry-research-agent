## 二、逐项缺陷深度解剖与证据链

### 1. NEW-10 (P0)：核心龙头宁德时代行情估值指标缺失

- **真实运行现场**：
  在本次新能源汽车真实任务中，用户明确指定了 8 家核心 A 股上市公司。但在最终产出的研报中：
  - 宁德时代的营业收入（4,237 亿元）、净利润（722 亿元）、现金流（1,332 亿元）全部精确入库；
  - 但其 **`market_cap`（总市值）和 `pe_ttm` 均为 `None`**；
  - 在第 14 页的图表脚注中，系统不得不打印出：`“集中度计算基于本报告核心样本9家……宁德时代缺少市值数据，净利润集中度未按市值加权，仅按绝对利润额计算。”`
  - 在图 1（总市值集中度）和图 2（流通市值集中度）中，万亿市值的宁德时代**完全隐形**！
- **根本原因**：
  - [`agent.py#L61`](file:///Users/panheng/Desktop/同花顺赛题/a17-industry-research-agent-agent-chart-mvp-sync/agents_core/data-fetcher/data_fetcher/agent.py#L61) 规划器为已知核心标的规划了 `hithink-basicinfo-query` 和 `hithink-finance-query`。问财的财务三表接口只返回三表科目，不返回当期实时总市值与市盈率；
  - 泛选股任务 t2（`动力电池 正负极材料 电解液 A股 总市值大于30亿元 按总市值降序`）因问财多重关键词语法未能正确召回标的（返回 0 条记录）；
  - 核心标的缺少一条类似 `[标的名] 最新总市值 动态市盈率 涨跌幅` 的针对性行情查询任务。


- **根本原因**：
  - 问财泛选股任务 t4（`智能座舱 自动驾驶 A股...`）通过概念匹配，将带有“无人驾驶后视镜”、“车载摄像头”概念的中际旭创、海康威视、立讯精密选入；

### 4. NEW-13 (P1)：产业链拓扑图徽章误标股票价格与环节错位

- **真实运行现场**：
  在 PDF 第 11 页图 6《新能源汽车产业链上中下游拓扑（代表企业）》中：
  - **上游**：宁德时代，右侧绿色徽章醒目标注 **`293.5元`**；
  - **中游**：比亚迪标注 **`84.34元`**，长城汽车标注 **`13.91元`**；
  - **下游**：赛力斯标注 **`46.33元`**，长安汽车标注 **`7.03元`**；
  - 整个图表不仅将股价作为业务环节徽章展示，而且将赛力斯和长安汽车两家整车厂归入“下游”，而比亚迪和长城汽车却在“中游”！
- **根本原因**：
  1. 产业链节点在 `agent.py` 中预留了 `margin` 字段用于标注毛利率（如 `毛利:26.3%`）或环节赛道。ChartLLM 缺乏强约束，将最新股价填入了 `margin`，`render.py` 未做数值语义校验直接格式化上屏；
  2. 智能体在下游缺少公司时，采用机械重平衡（Rebalance）强行把同属乘用车制造的赛力斯和长安汽车调配到下游，违背了汽车行业上下游划分的常识。

### 5. NEW-14 (P1)：时序分箱截断导致对比图年份严重缺失

- **真实运行现场**：
  图 13 仅对比了 2021 和 2022 年，标题也被迫加上了“（2021-2022）”。而实际上底层数据库中，长安汽车和亿纬锂能 2021~2025 年全部 5 年的财务数据一应俱全。
- **根本原因**：
  [`agent.py#L820-L828`](file:///Users/panheng/Desktop/同花顺赛题/a17-industry-research-agent-agent-chart-mvp-sync/agents_core/chart-generator/chart_generator/agent.py#L820-L828) 在调用 LLM 生成图表前进行证据分箱（`_bin_evidence_for_prompt`）：
  ```python
  for grp in other_ts:
      grp_sorted = sorted(grp, key=lambda x: str(x.period or ""))
      if len(ts_selected) + len(grp_sorted) <= 35:
          ts_selected.extend(grp_sorted)
      else:
          rem = max(0, 35 - len(ts_selected))
          if rem > 0:
              ts_selected.extend(grp_sorted[:rem])  # <--- 粗暴腰斩！
          break
  ```
  当剩余配额 `rem=2` 时，代码直接将完整的 5 年序列切片为 `[:2]`，使得传入 LLM 的证据只剩下 2021 和 2022 两年！LLM “巧妇难为无米之炊”，只能生成两年对比图。完整时序应当整组保全，严禁截断破坏时序连续性。

## 三、整改与优化技术方案建议

1. **针对 NEW-10（核心标的市值补齐）**：
   在 `DataFetcherAgent` 首轮规划时，为用户指定的 `must_include_entities` 不仅派发基础信息与财务报表，同步派发一条轻量级实时行情任务（例如：`f"{comp} 最新价 总市值 动态市盈率"`），确保核心标的市值与估值指标 100% 入库。
2. **针对 NEW-11（通用化行业纯度过滤器）**：
   重构 `_is_industry_relevant`：基于申万/同花顺一级行业与二级行业分类，动态匹配研报主题关键词（如主题包含“汽车/电动/动力电池”，则将非汽车/电力设备且概念占比微弱的纯通信、石油、安防标的移出主标的池）。
3. **针对 NEW-12（多序列对比柱状图支持）**：
   重构 `render.py` 中 `comparison_bar` 的渲染器，支持多组并列分组条形图（Grouped Horizontal Bars），或者在检测到多序列时退回为标准簇状垂直柱状图（Grouped Vertical Bars），并生成清晰图例。
4. **针对 NEW-13（产业链节点语义纠偏）**：
   在拓扑图生成逻辑中，将节点徽章字段与股价完全解耦，优先标注“主营产品/赛道环节”，禁止填入带有“元/股”的股价字符串；汽车产业链严格遵循：上游（电池/材料/零部件）$\to$ 中游（整车总装研发）$\to$ 下游（销售/补能/出行运营）。
5. **针对 NEW-14（时序分箱原子性保证）**：
   在 `_bin_evidence_for_prompt` 中，时序序列必须按“公司-指标”原子组进行吸纳，若剩余配额不足以容纳整条时序曲线（如不足 3~5 年），则不再截断切入，防止向 LLM 提供断头残缺时序。
6. **针对 NEW-15（图表家族多样性控盘与标签防碰撞）**：
   在图表装配算法中增加 `donut/pie` 数量硬上限（最多不超过 2 张，且严禁同一维度总市值与流通市值同时出环形图）；组合图在检测到柱顶与折线点纵坐标接近（距离 < 18px）时，强制将折线标签向上偏移或将柱顶标签内嵌至柱身内部。
