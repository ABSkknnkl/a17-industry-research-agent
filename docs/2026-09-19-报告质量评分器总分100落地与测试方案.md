## 2. 生产侧：总分 100 评分模型（`report_fusion/quality.py`）

保持上一版 7 维分配（L1 ≥90、L2 ≤10、LLM 不进阻断），用于生产与前端展示：

| # | 维度 | 权重 | 数据来源 | 算法（代码可算） |
|---|---|---|---|---|
| 1 | 结构完整度 | 20 | Agent4 chapters | 章节比+小节比各 10 分，`min(10, round(10*实际/expected_*))` |
| 2 | 证据覆盖率 | 25 | Agent2+4 | `25 * |used∩known|/|used|`；used 空 → 0 + reason |
| 3 | 引用一致性 | 15 | Agent2/3/4 | 未知 claim/evidence/chart 每类 −5，扣到 0 |
| 4 | 维度覆盖 | 15 | Agent2 `dimension_coverage` | supported=1/partial=0.5/insufficient=0，`15*avg`；缺字段 → 0 + reason |
| 5 | 图表嵌入 | 10 | Agent3+4 | 每张就绪且被引用图 1 分，上限 10 |
| 6 | 风险披露 | 10 | Agent5 研究边界 | 风险全披露 → 10，按比例扣 |
| 7 | 表达质量（L2 可选）| 5 | Agent4 可读性 linter + 可选 LLM | `max(0, 5*(1-hit_ratio))`；LLM 未启用只用 linter |

- 扣分正则化不越界、不出现负分；`total_score = Σ分项`，单测断言恒等。
- `blocking_issues` 非空 → `passed=False`，**仍输出总分**；导出只认 `passed`。
- 契约新增（同上一版，三处同步）：`total_score(0-100)`、`score_breakdown[{dimension, score, weight, max_score, reason}]`、`thresholds{good:90, warn:70}`。
- 配置进 `config.py`：7 项权重 + 90/70 阈值；单测断言权重和 == 100。

## 3. 评测侧：Q 类原子判定项（EVALUATION_PLAN §4.11 新增）

注册进 scorer 表（F0-07 自动校验注册完备），输入 = transcript 提取的标准评分对象：

| # | 判定项 | 检查点 | 一票否决 |
|---|---|---|---|
| Q1 | 总分一致性 | 评测重算 `total_score` 与生产 `total_score` 逐分相等（防漂移） | ✅ |
| Q2 | 分项加和 | `score_breakdown` 各项 score 之和 == total_score；无负分；各自 ≤ max_score | ✅ |
| Q3 | 结构扣分正确 | 章节/小节缺 → 结构项按公式扣至预期值 | — |
| Q4 | 引用扣分正确 | 未知 claim/evidence/chart 命中 → 引用一致性项扣至预期值 | — |
| Q5 | 缺口必扣 | `used` 空 / dimension 缺字段 / 风险未披露 → 对应项 0 + reason 非空 | ✅ |
| Q6 | LLM 隔离 | L2 表达软分启用时 temp=0/模型版本入 manifest；未启用时该项 0 且 reason 标注"未启用"；LLM 分数不并入 L1 小计 | ✅ |
| Q7 | 表达软分范围 | 表达项 ∈ [0,5]；只影响该项，不影响其余 95 分与 passed | — |

评测命中缺陷 → `fail`/`blocked` 语义沿用 §12.1（blocked 等同 fail，绝不静默）。

## 4. 校准：golden set（判定"评分器好不好"的唯一权威）

复用 `readability_calibration.py` 的「回归库 + 考卷 + 阈值曲线」三件套模式，新建：

```
eval/calibration/report_quality/
├── samples_v1.json        # 30-50 条报告快照（真实产物 + 变异产物），三档分布
├── human_scores_v1.json   # 2-3 人独立打标真值（对齐后定稿）
└── reports/               # 跑批结果（阈值曲线/κ/Spearman）
```

判定条件（CI 断言）：
- 人机一致性：二元 κ ≥ **0.6**（复用 `cohen_kappa_binary`）；连续 Spearman ≥ 0.7 或 MAE ≤ 8
- 人先对齐：标注入员间 κ ≥ 0.6，不一致样本讨论定稿、剔除歧义
- 防作弊：标注真值永不进任何 few-shot/微调；`samples_v1` 版本号入 `run_manifest`，换版本 = 新环境
- 漂移复查：每季度抽 10 条新样本复核，κ 跌破门禁 → 评审阈值/规则

## 5. 变异套件（判别力测试）

`eval/mutators.py` 扩展报告级 `Mutation` 枚举（沿用现有 `apply_mutation/bisect_layers` 骨架）：

| 变异 | 期望 | 判据 |
|---|---|---|
| `DROP_CHAPTER` / `DROP_SECTION` | 结构项扣分 | Q3 |
| `FAKE_UNKNOWN_CLAIM` / `FAKE_UNKNOWN_EVIDENCE` | 引用项扣分 | Q4 |
| `DROP_EVIDENCE_LINK` | 覆盖率下降 | Q1/Q3 |
| `MISSING_DIMENSION` | 维度项 0 + reason | Q5 |
| `CHART_REF_MISMATCH` | 图表项扣分 | Q4 |
| `OVERLONG_PARAGRAPH` / `REPEATED_PARAGRAPH` | 表达项扣分（L2） | Q7 |

门禁沿用 §2.5：**变异存活率 ≥95%**（仍正确或正确拦截），失败 bisect 归因记录首个失守层；每变异纳入 golden 抽样。

1. **先生产分数**（M1）：`quality.py` 重构 + 契约扩展 + config；生产单元/契约/一致性绿
