## 七、脚本与复现

`add_a2_review.py` 是幂等的：每次运行都从 `~/Downloads/A17_智研天工.pptx`（27 页基线）重建，不会叠加改动。

```
cd ~/Downloads/A17_编辑工作
python3 add_a2_review.py
# 产出：_stage_edited.pptx（28 页）
```

内部四步：zip 层复制 `slide16.xml` → 新增 part 与关系 → 按 shape id 批量换文案（**只换文字，不动几何**）→ 全盘页码/总页数/导航列表顺延。

如果要复用它生成 A1 或 A5 审核页：改脚本顶部的 `REPL` 字典（键是形状 id，用 `python-pptx` 遍历打印即可拿到）与 `LIST` 列表，其余不用动。

**注意两个坑**（脚本里已处理，改动时别回退）：
- 形状 id 在 XML 里存在于 `p:cNvPr/@id`，不是 `p:sp/@id`，复制形状必须改前者，否则同一页出现重复 id，PowerPoint/WPS 会提示修复。
- 第 11 页阅读顺序行的四个元素是"底卡 + 序号胶囊 + 数字 + 标题"，克隆末行后必须按 id 精确分组重排，不能按坐标排序，否则胶囊和标题会错位叠字。
