A3 / CHART GENERATION · 全貌

智能体 3 不是“产业链图生成器”，
是“图表编译与出版检查器”

它把 A2 的解读报告、证据索引和用户题面，编译成一套按 7 章落位、逐点可追溯、单位同轴、能进 PDF的图。
产业链图只是 16 种图型里最特殊的一种，不是 A3 的全部。

INPUT
A2 解读报告 + 证据索引interpretation_report.json / dataset.json / 题面卡
OUTPUT
一套图，不是一张图chart_result.json + 每图 SVG/JSON + preview.html + 抑制/补采清单
一句话：先判断数据能支撑什么图，再把数据整成同轴同口径的二维表，再逐点挂证据，最后过发布契约与质检；数据不够就不画。
01INTAKE

读料与排雷

先判断这轮到底能不能画，不拿模型记忆补数。

  • 输入：A2 报告、证据索引、题面卡、数据集
  • 先剔源冲突：A1/A2 口径不一致的点，不进入图
  • 没有数值/产业链证据 → 直接抑制，不为凑数硬画
  • 按 7 章检查：图该落在 CH-01—CH-07 哪一节
→
02SELECT

选型

不是“有数据就画柱状图”，而是按数据形态选型。

  • 时序 → line/area；规模+增速 → combo；截面 → bar/comparison/horizontal
  • 构成 → pie/donut；多维 → radar；二维定位 → scatter/bubble；层级 → treemap；分布 → boxplot
  • LLM 提候选 + 确定性兜底，避免某次只规划两三张
  • 技能路由：chart-selection / financial-charting / chart-readability / industry-chain-visualization
→
03FORMULATE

数据整形

先把异源证据压成一张“同轴同口径”的二维表。

  • NormalizedDataTable：类目、系列、单位、点级证据一一对齐
  • 缺失值写 None，绝不填 0；零轴不截断
  • 单轴禁止混量纲；金额统一到亿元/万元；比率分子分母同期间同口径
  • 图有据、点也有据：每个点挂 record_id，不是只挂图级 evidence
→
04COMPILE

编译渲染

一条数据契约，同时喂给网页和 PDF，图不能两副面孔。

  • ECharts option + 原生 SVG/HTML；前端可交互，PDF 可矢量
  • publication.py 逐点核对：图上每个值 == 数据契约
  • 轴名、单位、图例、观察期必须一致；不一致就拦
  • presentation.py 只改展示，不改 xAxis/series/evidence
→
05AUDIT

质检 / 抑制 / 补采

能画 ≠ 能发；过不了门禁的图，宁可不发。

  • Linter：证据、零轴、样本量、构成图、雷达维度、混合量纲、多样性、柱图占比
  • 失败 → 确定性修复 / LLM 修复；仍失败 → 抑制并写原因
  • 硬需求缺数据 → data_demands，回 A1/A2 补采，不凭空补
  • 产物：chart_result.json / charts/*.svg / preview.html / events.jsonl

16 种图型：产业链只占 1 格

ChartType 白名单是硬边界；模型不能发明第 17 种图。

line时序趋势
bar截面排名
comparison_bar多组对比
horizontal_bar长标签排名
diverging_bar正负分化
combo规模 + 增速双轴
area累计趋势
scatter二维定位
bubble三维气泡
pie构成占比
donut环形构成
radar多维能力
heatmap矩阵对比
boxplot分布（≥15 点）
treemap层级（≥8 项）
industry_chain产业链拓扑 · 专用 SVG

产业链图的特殊之处：它是唯一带“结构/归属”语义的图型，所以单独配了 lane_grid 渲染器和 topology 裁判-修复；其他 15 种走通用数值图流水线。

真实跑出来的形态

不是“一张产业链图打天下”，而是一套按题面组织的图。

15 张新能源交付图：1 张产业链 + 14 张数值图
5 / 5Q1—Q5 题面全覆盖，状态 published
2 combo
5 line另有 2 张对比柱、1 张柱图、4 张横向条形图
49 张另一次通用真跑：15 张请求，11 张出图，49 个候选被抑制

质检出局：图型不适配、样本量不足、量纲混轴、点级证据对不上、柱图占比 > 40%、图型少于 3 种，都会被 linter 拦下。
“抑制”不是失败，是不拿错图充数。
