## 1. 定位：这两段在投研生产链上的位置

卖方研报的内控是三段式：**编制 → 复核 → 签发**。

| 环节 | 承担者 | 本项目的实现 |
| --- | --- | --- |
| 编制 | A4 | 把研究结论装配成符合范式的章节文本，并逐段挂接底稿索引 |
| 复核 | A5 | 以整份报告为单位做底稿校验、勾稽复核、图表合规、完备性判定 |
| 签发 | A5 + 状态机 + 人 | 按控制点结论给出四类出口，人工审核门放行后才结束 |

**A4 解决"写得合规"，A5 解决"发得出去"。** 这两句是你所有回答的根。

## 2. A4：AI 如何以金融专业视角写章节

### 2.1 输入是编制任务书，不是一句命题

A4 收到三份料，少一份 JSON 直接报错，不硬编：

1. **A2 解读报告**：证据白名单、洞察、财务比率、必答题覆盖表；
2. **A3 图表结果**：哪些图已就绪、每张图推荐哪一章、图内每个点对应哪些证据号；
3. **题目清单、人工反馈、写作选项**（模板、篇幅）。

每章另配一个**独立资料袋**：最多 60 条证据、8 条洞察、25 条发现；一张图只能进一个章节（单图单处锁，防止同图跨章重复充数）。资料袋有 50 万字节上限，超限先丢可选背景，**证据白名单与必答题永不丢**；仍丢不下则报错，不静默截断。

### 2.2 六条写作纪律（每条都对应投研规范）

| 纪律 | 代码事实 | 金融含义 |
| --- | --- | --- |
| 论点驱动 | 每段只承担一个判断，先结论后论据 | 卖方研报的 thesis-driven 写法，不是资料汇编 |
| 一段一数 | 除图表解读段外，每段至多一个关键数字 | 正文留判断，明细留图；避免数字堆砌 |
| 可复算 | 同比、复合增速、占比、百分点必须写明指标、期间、口径，并在该段 `evidence_ids` 绑定全部原始操作数；缺任一操作数改写为证据缺口 | 读者能拿两个原始数据把这个数复算出来 |
| 口径原样 | 计量单位、期间、合并范围、来源不得改写；只允许可复算的同维度换算（辆→万辆） | 不得把"万辆"写成"辆"，不得擅自换合并范围 |
| 图号不作依据 | `[CHART-xx]` 只能定位图表，不能充当数值或因果依据 | 图是证据的呈现，不是证据本身 |
| 禁用空话 | 禁"值得关注""总体向好""显著""指数级"等不可证伪表述 | 对应"避免误导性陈述"的要求 |

### 2.3 三条硬口径规则（最能体现"金融专业"的地方）

**（1）可比性五项门槛。** 样本、期间、合并范围、币种、单位，缺一项即退出横向对比。
典型案例：比亚迪三年营收均在库、期间为整年，但接口未给金额单位，系统判定"单位不可核验"，不进入对比。**数据在而不可比，与数据缺失是两回事**——这条差异在一致性清单里查得到。

**（2）全局事实锚点。** 全篇总市值必须按 `global_facts` 统一，禁止跨章出现数量级矛盾。这正是 A5 印前复检要对账的那一条。

**（3）净现比只能引用，不能自算。** A4 只允许引用 A2 已核验的净现比（经营活动现金流／**归母净利润**），禁止拿合并净利润重算；口径不符的断言，落盘前当场改写为缺口句"缺少同口径归母净利润，净现比无法计算"，并写入 `content_audit`。亏损年度标注"不适用"。

### 2.4 写完立刻自校——这是 A4 最核心的活

逐段核四件事：数字有没有挂证据号、证据号在不在白名单、图有没有串章、总市值有没有前后矛盾。

- 不合格：**定点重写那一段**，最多 3 轮；仍不合格则删句，或改写为"本项量化解读未通过证据核验"，全程留痕；
- 跨章冲突：**只登记、不改正文**（写入 `content_audit`），是否阻断交 A5 按严重级别判。

"复核人不动笔"是内控原则，也是防止模型擅自改数。

### 2.5 失败策略（决定你能不能承诺"不会编"）

HTTP 3 次退避 → 章内 3 轮定向修复 → 段落隔离 → 确定性兜底稿（打 `used_fallback` 标）→ 全篇 `partial` 如实透传 → 停在人工审核门。

诚实点：**A4 质检未过不阻断流转**，是 A5 把它压成受限草稿。设计意图是"让人看见问题"，不是"悄悄停下"。

## 3. A5：AI 如何以质控与签发视角收口

### 3.1 输入是契约，不是内存

三份落盘 JSON：`interpretation_report.json`、`chart_result.json`、`chapter_result.json`，缺一份即报错。A5 不直接调 A4，只认落盘文件——可复跑、可审计。

### 3.2 编辑红线：总编拿的是红笔，不是钢笔

| 红线 | 具体约束 |
| --- | --- |
| 只编辑不新增 | 可写摘要、结论、过渡句、统一术语；不得补外部事实、数字、来源 |
| 数字零改动 | **100% 原样保留所有数字**，含股票代码、年份、列表序号 |
| 证据复用 | 必须完全复用原段 `evidence_ids`，不得伪造编号 |
| 规则过滤 | 模型提的每处改动逐条过确定性校验，不过退回原文 |
| 调用上限 | 最多 3 次模型调用（选技能／编辑／修段落） |

### 3.3 四类复核（对应质控清单）

| 复核 | 内容 | 对应的投研动作 |
| --- | --- | --- |
| 输入体检 | 7 章 21 节齐备、A4 `quality.passed`、有无兜底稿、有无未知证据号 | 接收稿件时的形式审查 |
| 勾稽与一致性 | 跨章同指标同值同口径；总市值归一（**仅在"总市值"语境改写，公司自身市值不动**） | 报告级数字勾稽 |
| 图表合规 | 图是否就绪、图点能否被数据复算、图文是否一致；A17 五问模板要求 15 张指定图齐备，缺一张即阻断 | 图表合规复核 |
| 完备性 | 必需研究数据缺口、指定年度指标缺口，按硬性要求判定 | 资料完备性审查 |

未知 `evidence_id` 一律阻断——底稿索引对不上，就不许声称完成。

### 3.4 印前复检（S-05）

对**最终要导出的那个版本**重新验一遍，**不复用编辑前的诊断**——因为嵌图后图号、段落位置都变了。等同于印前对清样，不是编辑前体检。

### 3.5 三格式同源与签发

同一份版面视图渲染 md／html／pdf；结论一改，三份全部按同一视图重印，禁止某一版停留在旧结论。

`delivery_status` 由"实际成功格式 + 最终校验结论"共同决定，给出四类出口：

| 出口 | 代码状态 | 投研含义 |
| --- | --- | --- |
| 正式报告 | ready | 过质控，可对外 |
| 带提示交付 | draft_with_warnings | 可有条件使用，须附提示 |
| 受限草稿 | ready_with_limits | 内部讨论稿，禁止正式放行 |
| 阻断交付 | hard_blocked / delivery_blocked | 打回，不许出 |

**硬阻塞不可绕**：`hard_blocked`、`delivery_blocked`、`exports_stale`、人工编辑后的质检失效，一律禁止批准；人工只能绕过 `partial`／质检未过／产业链交付未完成这三类软阻断。

### 3.6 版本失效

人工改动 A4 正文后，状态机把 A5 置 pending、打 `exports_stale`、删除旧导出，只能重新融合。**旧 PDF 不得冒充新版。**

## 4. 为什么这两段必须由金融岗讲

### 4.1 五个金融判断点，全在这两段

| 评审关注点 | 系统里的机制 | 你的落点 |
| --- | --- | --- |
| 口径说不说得清 | 五项可比性 + 可复算原则 | 单位、期间、范围、币种、样本 |
| 数字能不能复算 | 段落级 `evidence_ids` 绑定全部操作数 + 图点核验 | 读者拿原始数据能重算出这个数 |
| 结论有没有越界 | 禁用词表 + 待归因 + 净现比"不适用" | 不把推断写成事实，不给评级目标价 |
| 交付可不可信 | 四类出口 + 硬阻塞不可绕 | 正式／提示／受限／打回的分级 |
| 出了错能不能查 | `content_audit` + 证据索引 + 修订快照 | 谁改的、改了什么、能否回溯 |

### 4.2 你的量化训练，正好对应四个抓手

- 对"样本、期间、单位"的敏感度 = **五项可比性门槛**；
- 对"因子口径漂移"的理解 = **研发费用率两套量纲、毛利率算术平均 vs 加权**；
- 对"回测不许偷看未来"的纪律 = **不得把预测写成历史事实，情景参数必须标假设**；
- 对"可复现"的要求 = **落盘 JSON 契约、三格式同源、重跑留痕**。

这四条不用学，你本来就有；只需要知道系统把它们落在哪。

## 6. 可直接背的三段口述稿

### 6.1 A4（约 2 分钟）

> 智能体 4 是章节编制环节。它拿到的不是一句"写个新能源报告"，而是一份编制任务书：A2 的证据白名单与必答题覆盖、A3 的就绪图表与图文映射、以及人工反馈。每章配一个独立资料袋，最多六十条证据、二十五条发现，一张图只能进一个章节。
>
> 它按七章二十一节逐章编制，写作上守六条纪律：论点驱动，每段只承担一个判断；除图表解读段外每段至多一个关键数字，明细留图；同比、复合增速、占比和百分点必须写清指标、期间、口径，并把全部原始操作数绑定到这一段；单位、期间、合并范围原样保留；图号只能定位，不能当依据；不可证伪的词一律禁用。
>
> 最能说明专业性的是那条门槛：样本、期间、合并范围、币种、单位五项齐备，才允许横向对比。比亚迪三年营收都在库里、期间也是整年，但接口没给金额单位，系统就判"单位不可核验"，不进入对比——数据在而不可比，和缺数据是两回事。
>
> 写完它立刻自校：逐段查证据号、查数字能否复算、查图有没有串章。不合格就定点重写那一段，最多三轮；再不行删句或标注"未通过证据核验"，全程留痕。

### 6.2 A5（约 1 分 40 秒）

> 智能体 5 是报告级复核与签发环节，不是排版。它只吃三份落盘 JSON，做四类复核。
>
> 第一，输入体检：七章二十一节齐不齐、上一阶段质检过没过、有没有兜底稿、有没有未知证据号。
> 第二，勾稽：同一指标跨章必须同值同口径。总市值我们对过账，以三点五二万亿元为基准；但只在"总市值"这个语境改，公司自身市值不动。
> 第三，图表合规：图点能不能被数据复算、图文是否一致。五问模板要求十五张指定图，缺一张就阻断。
> 第四，完备性：必需研究数据的硬缺口、指定年度指标的缺口，不过就不许宣告完成。
>
> 它的编辑红线是只编辑不新增——能写摘要、写过渡、统一术语，不能加一个新数字；模型提的每处改动都要过规则过滤，不过退回原文。
>
> 最后是签发，四类出口：正式报告、带提示交付、受限草稿、阻断交付。硬阻塞不可绕过——人工改过上一阶段，旧导出会作废，必须重新融合。读者看到的 [1][2]，是这一步才生成的。

### 6.3 证据链（约 40 秒）

> 一条数字的旅程是四步：A2 给每条原始记录发编号；A4 把编号写进段落的 `evidence_ids`；A5 只收录真被引用的记录，生成证据目录并出 CSV；排版时才变成读者看到的 [1][2]。所以现场点开一个角标，能一路回到原始记录——那次交付挂了 113 条证据索引，19 处接受编辑，1 条留存警告。

**注意**：口述稿里的数字必须与现场演示的那份报告一致，见第 10 节。

## 7. 高频问答（金融口径版）

| 评委问题 | 标准答法 |
| --- | --- |
| 为什么不让一个模型一口气写完七章？ | 长文本会退化、章节间会串味。七章并发、每章独立资料袋，控 token 又保证证据定位准；代价是跨章一致性要靠全局数字锚点加印前复检来补。 |
| 怎么保证不编数字？ | 三层：提示词限定只能用本章资料袋 → 每段强制挂 `evidence_ids` → 确定性审计比对数字与白名单。不合格定点重写，最多三轮，再不行删句留痕，绝不静默放过。 |
| 提示词写了那么多规矩，模型不听怎么办？ | 不依赖模型自觉。提示词只是第一道，模型产出只算候选稿，真正的兜底是代码审计——数字、证据号、图号、总市值量级都按规则比。 |
| 模型挂了会怎样？ | 退避三次 → 章内三轮修复 → 段落隔离 → 规则拼一份打标的兜底稿 → 全篇 `partial` 如实上报，停在人工审核门。 |
| A5 为什么要重写一遍？ | 不重写。事实已在 A4 逐段核过，再生成一次等于重新引入幻觉。A5 是收口阶段，"只编辑不新增"是红线，最多三次调用且每次都被规则过滤。 |
| "四大审校技能"是四个子智能体吗？ | 不是。实际是五份写给模型的编辑规范；技能"选择"有一次模型调用，"执行"与校验全是规则代码。 |
| 为什么有的报告是"受限草稿"？ | 有硬伤时照样产出内容供审阅，但不盖章、页眉标明、禁止正式放行。这是可审计的降级，不是静默成功。 |
| 人工"带警告放行"能绕过所有门禁吗？ | 不能。只能绕过 `partial`、质检未过、产业链交付未完成三类软阻断；`hard_blocked`、`exports_stale`、人工编辑后的质检失效一律禁止批准。 |
| 改了 A4 正文，旧 PDF 还能下载吗？ | 不能。状态机把 A5 置 pending、打 `exports_stale`、删旧导出，必须重新融合；旧版不得冒充新版。 |
| 证据怎么从原始数据追到 PDF？ | A2 发号 → A4 每段挂 `evidence_ids` → A5 汇总只收录真被引用的记录并出 CSV → 排版时生成 [1][2]。图号同理。 |
| 这套设计的边界在哪？ | 四层：规则只能查"有没有挂证据"，查不出"证据本身对不对"；上游没有的数一律不补，只写证据缺口；不放宽审核门、不出投资建议；成本可测算。 |
| 你们说"二十一节全并发"？ | 纠正：代码是**七章并发**，每章一次主模型调用，节不是并发单位。按代码讲更稳。 |

## 8. 三处必须按代码讲，否则当场穿帮

1. **"21 节并发" → 实际是 7 章并发**，每章一次主模型调用。
2. **正文里没有 `[^R-xxx]` 证据角标** → A4 正文只有 `[CHART-xx]` 图占位符，证据编号在结构化 `evidence_ids` 数组里；可见的 [1][2] 由 A5 生成。
3. **"四大审校技能" → 实际 5 份规范**（多一份"核心逻辑跟踪台账"）。前端播报文案是 4，被问到照实说。

另外两处措辞：A4 的 `status` 实际只有 `completed`／`partial`（`failed` 是适配层防御分支）；A4 质检未过**不阻断**，是 A5 压成受限草稿。

## 9. 红名单：不能说的话
