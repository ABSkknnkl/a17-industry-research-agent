A3 / CHART GENERATION · 算法 3 · 先固定框架，再填内容

智能体 3：产业链图不是“画”出来的，是“判”出来的

模型只负责往固定槽位里填有出处的企业；结构、口径、上限、修复规则、版式，全部由代码定死。
它解决的不是“图好不好看”，而是图上的产业链关系是不是真的、能不能交。

INPUT
A2 拓扑草稿 T节点 / 连线 / 企业 / 证据编号，先由模型提
OUTPUT
clean / repaired / fallback带证据编号的图，或合法降级；绝不带错图入稿
结构给死内容放开缺失显式修不好降级
01SKELETON

结构骨架

先决定“分几段、有哪些格子”，再谈填谁。

  • 六类骨架：离散制造 / 消费 / 流程 / 医药 / 数字 / 服务
  • 14—16 个固定槽位：每类有自己的列头和格子
  • 模型只能填，不能增删改；核心位置、段数、上限写死在常量
→
02PROFILE

行业画像

把“行业常识”从模型脑子里，搬到可审计的文件里。

  • 25 份画像 JSON：每份给这个行业四样东西
  • 龙头名单 / 认证机构 / 能力卡词表 / 上下游清单，另加一份禁用词
  • 缺画像时，生成和校验会同时降级；不靠模型临场补常识
→
03RETRIEVAL

联网取证

每个格子填谁，必须来自检索片段，不是模型记忆。

  • 先清空非核心企业，上一站顺手写的名字不可靠
  • 4 段 × 2 条 = 8 条检索：上游 / 中游 / 下游 / 配套
  • 片段按槽位归类；某格有结果就整组替换，不新旧混放
  • 企业名必须能在片段里找到；找不到就空着，显示“暂无”
→
04JUDGE + REPAIR

校验 + 修复

裁判和修理工共用同一把尺；修不好就合法降级。

  • 七条硬约束：编号唯一、阶段合法、唯一核心、企业唯一、实物流不指研发、度数 8/12/16、证据可回查
  • validate → repair → 复验；修完再跑同一批判据
  • 三态输出：clean / repaired / fallback_flat
  • 修不好退回扁平结构，仍是合法结果，不硬拼
→
05RENDER + CHECK

渲染 + 体检

图怎么画，也是一条硬契约，不是模型随手排版。

  • 三列目录式，不是工艺流程图；整机并入中游顶部大卡
  • 卡片零连线，只留 2 根列间粗箭头；1600×900
  • 图上不许裸数字；环节名、企业名逐字出现在图里
  • 体检不过就降级，不出图；体检项包括轴 / 图例 / 单位

边界：答辩时主动说，反而加分

这套算法不是“万能正确”，它保证的是结构和归属不出系统性错误。

它保证：有哪些环节、每段放什么、什么算错、错了怎么修，不由模型临时决定。
它不保证：“这个行业只有这些环节”。三列四段只是一种视图，产业也可能是网络、平台生态、服务履约链。
仍未解：每条“企业属于某环节 / 企业供货给谁”的独立证据，还是 v2 方向；当前更多是“槽位 → 名单 → 规则修名单”。
展示去重：“一家公司只出现一次”是为了版面不重复，不等于真实世界它只参与一个环节。
不要把“fallback_flat”说成失败：它是合法降级，宁可扁平，也不带错图。
