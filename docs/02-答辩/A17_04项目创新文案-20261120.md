## 04 分隔页

- 眉标：PROJECT INNOVATION
- 主标题：项目创新

- 目录：4.1 并发编排｜4.2 证据血缘｜4.3 写作纪律｜4.4 图表治理｜4.5 一致性审计｜4.6 人机门禁

## 4.1 并发编排与版本隔离

- 眉标：PIPELINE & VERSION ISOLATION
- 主张：五个智能体是一条带状态机的流水线，不是五个脚本串行。
- 三个支撑：
  - 五段状态：数据、解读、图表、写作、融合，阶段不可越级，失败只回滚当前段。
  - 七章并发：A4 七章同时写，21 节按提纲落位，不是一章一章排队。
  - 版本隔离：每次提交生成 revision，r3 到 r15 可回滚；旧版本产物不能再审、不能签发。
- 对比句：端到端一次生成，出错整篇重来；我们拆成五个可重跑的工位。
- 配图：把 2.3 的状态流转图重绘成五条泳道，右侧接一条 r3 到 r15 的版本链。
- 口播：五个智能体不是五个脚本，是一条流水线；五段各有状态，七章并发写，出错回滚到基线。

## 4.2 证据血缘

- 眉标：EVIDENCE LINEAGE
- 主张：报告里的每个数字都是指针，不是一段文字。
- 三个支撑：
  - 五段 ID 链：record_id → evidence_record_ids → point_evidence_ids → evidence_ids / chart_ids → evidence_catalog。
  - 348 条证据目录：PDF 第 18 页的 [207][267][327] 可以逐条回到原始记录。
  - 悬空引用会被隔离或记录待核，不进交付稿；证据不支持，结论不保留。
- 对比句：常规引用是脚注，靠人记；我们的引用是 ID，机器能查。
- 配图：用第 20 页的五段链条，右侧放大 348 条目录和一条 [207] 的回查路径。
- 口播：报告里的每个数字都是一个指针；点开 207，能回到原始记录、单位和报告期。

## 4.3 分章写作纪律

- 眉标：SECTION WRITING DISCIPLINE
- 主张：先定角色，再写段落；模型只能在格子里填。
- 三个支撑：
  - 七章二十一节按提纲写，章节携带 chart_ids 与 evidence_ids，不另起结构。
  - 段落分三类角色：观点、证据、分析；观点段不许夹带没有证据的数字。
  - 正文只放 [CHART-xx] 占位符，编号由 A5 统一生成，七章不各编各的。
- 对比句：给一段提示词自由写，写完人再改；我们先把段落结构定死，再让模型填。
- 配图：第 23 页的段落组件局部，标出观点、证据、分析三色和 chart 占位符。
- 口播：我们不让模型自由写文章，先把段落角色定死，数字必须带证据号，图表只留占位。

## 4.4 图表治理

- 眉标：CHART GOVERNANCE
- 主张：图不是画出来的，是每个点先有证据。
- 三个支撑：
  - 15 张图全部由数据点生成，每个点绑 point_evidence_ids。
  - 缺数先定向补采：最多一轮、每轮最多两项；补不到就留缺口，不用示意数据凑图。
  - 图表选择有策略与回退：observe / apply / off，候选不合法就回确定性策略。
- 对比句：先画版式再找数，缺数就用示意；我们先验证据，再决定这张图能不能出。
- 配图：图表清单 + 产业链全景图 + 缺数回采对话框，三块并排。
- 口播：图不是先画版式再找数；每个点先有证据，缺数就补采，补不到就留缺口。

## 4.5 全文一致性审计

- 眉标：CROSS-CHAPTER AUDIT
- 主张：七章合起来一次审，冲突变成字段。
- 三个支撑：
  - 四维矩阵：结构、数值、引用、改动，每一维都有明确处理方法。
  - 归档样例：总市值最高 3.52 万亿、最低 1.09 万亿，按归档审计基准对齐到 3.52；19 处编辑接受、1 条警告留存、0 条拒绝。
  - 审计后仍停在待审：一致性通过不等于可签发，状态留给人确认。
- 对比句：合稿靠人通读，冲突靠记忆；我们把冲突做成可计算字段，逐条对齐。
- 配图：第 25 页的四维矩阵，右侧放 3.52 与 1.09 的对齐前后。
- 口播：七章合起来一次审，结构、数值、引用、改动四维过；冲突按归档基准对齐，改一处留一条记录。

## 4.6 人机门禁与同源交付

- 眉标：HUMAN GATE & SAME-SOURCE DELIVERY
- 主张：人改证据，系统关门；签发权始终在人手里。
- 三个支撑：
  - 反馈四字段：位置、问题、要求、验收；提交即绑当前 revision。
  - 人工编辑让原质检失效：r13 正式签发暂缓，阻断项写明报告经人工修改，需重新融合并完成质检。
  - 重跑 51 条全量质检 → r14 通过 → 确认 35 类风险 → r15 签发四份产物；PDF 25 页，CSV 348 条同源。
- 对比句：AI 生成、人点通过；我们人改证据、系统强制复验，签发权在人。
- 配图：三张关键帧，r13 暂缓提示、融合遮罩、r15 下载页，横排三格。
- 口播：人改一次，旧质检就失效，签发按钮直接关掉；重跑 51 条才能发，四份产物同一版。
