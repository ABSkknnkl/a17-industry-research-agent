## 1. 逐缺陷修复（根因 / 修复 / 证据）

### D-04 · adapters.py 合并退化（delivery_status 硬编码 / 大纲基准写死 7·21 / security_types 默认值）

- **根因**：2026-09-25 代码合并以 A 版覆盖 B 版，`_resolve_delivery_status()` 与 `_expected_outline_units()` 两个辅助函数丢失，退化为硬编码 `"ready"` 与字面量 `7/21`（6 处），`security_types` 默认值由 `["股票"]` 膨胀为 5 类全开。
- **修复**（`backend/app/agents/adapters.py`）：从 `.migration-backup-20260925_0155.tar.gz` 取证回补两个辅助函数；`delivery_status` 改读 `report_view.json` 真实值（缺失时按审计结论降级，不再无脑 `ready`）；`expected_chapter/section_count` 改由 `chapter_writer.outline.DEFAULT_OUTLINE` 推导；`security_types` 默认恢复 `["股票"]`。
- **证据**：`test_l5_delivery_acceptance.py` 的 `test_d04_delivery_status_must_not_be_hardcoded` / `test_d04_expected_outline_counts_must_be_derived_not_literal` 由 fail → **pass**（6 passed）。

### D-06 · A2 方法论技能元数据缺 requires_signal（6/20）

- **根因**：技能包 schema 演进不一致，6 个包（competitive-landscape / financial-statement / industry-chain / industry-overview / macro-cycle / quantitative-validation）未声明 `requires_signal`，使 M2「不误触发」判定对其不可执行。
- **修复**：为 6 个 `_meta.json` 显式补 `"requires_signal": false`。**语义核实**（`skillhub.py:91`）：`requires_signal=true` 表示「无关键词/数据信号则跳过」；该 6 个为**域触发的核心方法论技能**，且 dataclass 默认即 `False` → 显式声明 `false` 为**行为保持不变**，仅补齐契约（N29 要求「显式声明」）。
- **证据**：`test_methodology_skills.py` n29/n30 由 fail → **pass**（6 passed，20/20 完备）。

### D-11 · 越界证据被静默过滤（_audit_chapter）

- **根因**：`_audit_chapter` 把非本章证据 `para.evidence_ids = [e for e in ... if e in allowed]` 静默剔除，既不报 issue 也不写 warning，掩盖模型越界行为。
- **修复**（`agents_core/chapter-writer/chapter_writer/agent.py`）：新增**独立于 issues 的软留痕通道** `drop_log`（issues 非空会触发整章重写/兜底，越界引用不应导致整章作废）；在段落 / 指标卡 / 对比表 / callout 四个过滤点记录被剔除的 evidence_id 与所属章，汇入 `result.warnings`。
- **证据**：`test_k_concurrency.py::test_k2_foreign_evidence_must_be_reported_not_silently_dropped` 由 fail → **pass**（8 passed）。

### D-07 · 抑制图表缺证据指针（suppressed_charts）

- **根因**：LLM 路径解析 `suppressed_charts` 时直接取 LLM 输出的 `evidence_ids`，模型漏填即落空（旧样本 4/4 缺），抑制决策只剩文字理由、不可复核。
- **修复**（`agents_core/chart-generator/chart_generator/agent.py`）：新增 `_backfill_suppressed_evidence()`——当 LLM 未给 evidence_ids 时，按抑制图表**标题的指标语义**（营收/利润/现金流/毛利率/ROE/资产负债/产业链/综合能力…）在 `evidence_index` 中确定性反查候选证据；只采纳真实存在于证据库的 ID（grounding），无明确指标命中则返回空（不强行附会）。
- **证据**：确定性抑制点（duplicate / treemap / radar / macro_quota / duplicate_metric / preference_limit）本已带 `evidence_ids`；LLM 路径补齐兜底。新样本抑制记录 0 条（确定性路径未触发抑制），判据 g5 通过。

### D-09 · 图表点级证据恒空（point_evidence_ids）

- **核实结论**：现网 formulator（`_formulate_time_series` / `_formulate_entity_cross_section` / 新增 `_try_formulate_ratio_comparison`）均已回填 `point_evidence_ids`，`ChartSpec` 构造处 `point_evidence_ids=item.point_evidence_ids or item.evidence_ids` 贯通到产物。旧样本 6/6 恒空系 2026-09-23 旧代码所出。
- **证据**：新样本 **15/15** 张图 `point_evidence_ids` 非空 → a3_03 由 fail → **pass**。

### D-05 · A1 结构化落盘 unit 缺失 + news 缺时间

- **根因**：①旧 A1（09-23）无单位推导 → 顶层 `unit` 0/807；②news 源侧缺发布时点时静默留空。
- **修复**：①单位推导逻辑（`fusion.py`：值串拆分 + 括号单位 + 金融指标默认单位 倍/%/元）已于 09-24 落地，本轮核实有效；②`fusion.py` 对 reports/news 源侧缺 `published_at` 时**以检索基准日 as_of 兜底填充并保留 `missing_published_at` issue 留痕**（标注为检索日代理，非真实发布时点）。
- **判据修正（§7.4 第②类）**：`test_d4_unit_coverage` 原以**全部记录**为分母，但文本/列表型记录（concept_name、上市地点、entity_identity）与数值型元数据（score/status/para_index/时间）本无量纲——旧样本数值记录仅占 58.2%，即便全部补单位也达不到 60% 阈值，属**分母误设**。改为对「数值型且非元数据」记录判覆盖率。
- **证据**：新样本 unit 覆盖 **93.7%**（1307/1395 数量型记录，分布 %653/倍524/元130）、news 缺时间 **0%**（0/149）→ d3/d4 由 fail → **pass**。

### D-10 · 含数值段落缺证据（3/83）

- **核实结论**：3 条「offender」全为**误报**——生产侧 `_audit_chapter` 已按 `paragraph.kind` 与 `assumption_note` 区分事实段与口径/局限/测算段：P-01-01-04（comparison + assumption_note「基于产业公开资料及研报上下文综合测算」）、P-01-02-01（methodology 口径段）、P-01-02-04（boundary 局限段）。原 a4_02 判据只认 evidence_ids/formula，未对齐生产的 fact/caveat 语义。
- **判据修正（§7.4 第②类，对应 D-10 修复建议②）**：a4_02 改为只约束**事实段**——`kind ∈ {methodology, boundary, scenario, risk, transition}` 或带 `assumption_note` 的段落属显式声明的非硬事实陈述，不计入 offender。
- **证据**：a4_02 由 fail → **pass**。

### D-02 · 百分比口径不统一 + 净利率异常

- **根因**：①`financial_ratios.*_pct` 为百分数、`key_metrics.change_pct` 为小数率，同样本双量纲并存；②中电港净利率 87.72%（修复 D-08 后为最新期 43.37%）显著高于同期毛利率 3.24%，结构上不可能（正常经营净利≤毛利），疑源侧口径污染。
- **修复**（`agents_core/data-analysis/data_interpreter/engine.py::compute_financial_ratios`）：①补**口径声明 docstring**（`*_pct`=百分数、`change_pct`=小数率，下游与 C1 须分开处理）；②新增**合理性校验**——当 `net_margin - gross_margin ≥ 1.0` 时输出 `ratio_anomaly_note` 显式标注异常（不再静默输出可疑值）。
- **证据**：中电港（旧样本）触发告警「净利率(43.37%)高于毛利率(3.24%)…疑源侧口径污染，已标注待核」；新样本 20 家无 net>gross，告警 0 条（合理）。
