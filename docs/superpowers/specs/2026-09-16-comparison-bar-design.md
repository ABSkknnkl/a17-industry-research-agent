# Agent 3 涨跌幅对比图设计规格

## 目标

在现有 12 种 Agent 3 图表之外新增第 13 种正式图表 `comparison_bar`，用于比较同一组公司、标的或行业在两个可比周期内的涨跌幅。参考图只作为信息结构与布局依据，不复制其配色和版式；新图继续采用项目的 `finance_dashboard` 视觉系统。

## 用户可见效果

- 每个类别显示两根并列柱，默认系列示例为“年度涨跌幅”和“上周涨跌幅”。
- 纵轴围绕 0 展开，正值向上、负值向下，零轴加深以便快速判断方向。
- 涨跌语义遵循项目现有金融约定：正值红色、负值绿色；对比系列使用较浅色阶，并在图例中保持系列身份。
- 类别名称较长时自动倾斜并留足底部空间；类别较多时启用横向缩放，不挤压文字。
- Tooltip 同时展示两个周期的数值与单位，数据标签只在现有可读性阈值内显示。
- 前端 ECharts 与报告 SVG/PDF 输出保持标题、零轴、序列、颜色、数值和单位一致。

## 数据与公共契约

`comparison_bar` 使用现有 `ChartDataset(kind="categorical")` 和 `ChartPoint`，每个类别至少包含两个具名 series。无需新增新的数据点模型；只扩展图表类型与变体枚举。

同步修改以下公共契约：

- 后端 `ChartType`、`ChartVariant` 及工作流/分析/报告中的同义枚举。
- `contracts/schemas/` 中的图表结果 JSON Schema。
- 前端 `ChartTypeName`、展示名称和必要的类型联合。
- 报告层图表中文名称与 SVG 分派。

兼容性要求：已有 12 种类型的输入输出不变；未知或不满足双序列条件的数据不得伪装成成功的 `comparison_bar`。

## 路由与构建

新增 `build_comparison_bar_option`，由 Agent 3 服务按 `comparison_bar` 分派。构建器负责：

1. 按输入稳定顺序生成类别，按 series 名生成分组柱。
2. 保留正负值，不将纵轴强制从 0 开始；轴域覆盖最小值、0 和最大值并留出视觉余量。
3. 为每个点写入证据映射，沿用现有单位、脚注、注释和数据标签规则。
4. 在 `finance_dashboard` 下使用清晰零轴、圆角柱、金融红绿方向色和中性辅助色。
5. 为长标签设置旋转、截断与 dataZoom 阈值，保证桌面与窄屏可读。

路由接受 categorical 数据、至少两个非空 series，且各 series 能覆盖同一组类别；不完整覆盖时返回结构化拒绝原因，不静默补造 0。

## 报告与前端

前端继续消费后端生成的 ECharts option，仅新增“涨跌幅对比图”类型标签和响应式容器验证。SVG 渲染复用笛卡尔坐标绘制能力，并增加 `comparison_bar` 分派；零轴位置必须按真实数值域计算，不能假设位于图高一半。

第 13 张真实预览使用一组行业公司示例数据，覆盖正值、负值、长名称和两个周期，最终与现有 12 张图一起生成可打开的 HTML 与截图。

## 测试与验收

- 契约测试：后端、JSON Schema、TypeScript 三端均接受 `comparison_bar`。
- 路由测试：完整双序列接受；缺失系列、类别覆盖不一致和全空数据拒绝。
- Builder 测试：分组、零轴、正负值、方向颜色、长标签、dataZoom、证据映射与单位正确。
- SVG 测试：正负柱分居零轴两侧，系列与颜色可区分，文本已转义。
- 前端测试：显示“涨跌幅对比图”并正常挂载 ECharts。
- 回归验证：后端完整 pytest、Python 格式/静态检查、前端 verify/build 与 `git diff --check` 全部通过。
