## 0. 处理依据（三条）

1. **唯一事实源原则**：同一事实只留一个当前版本。后发现版本替代早期版本时，早期版本归档，不并存。
2. **可再生成原则**：报告样例、图表产物、视频、备份目录都能由代码或原始素材再生，不占 Git 与本地空间。
3. **过程归档原则**：一次性任务清单、合并计划、时点审查报告，完成后只保留在 Git 历史中，内容有价值的部分提炼进《开发总结》。
