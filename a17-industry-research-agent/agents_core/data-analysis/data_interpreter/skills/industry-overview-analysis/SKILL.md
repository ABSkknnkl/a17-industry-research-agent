# 行业概览方法

形成中性、可追溯的行业知识骨架，供后续内容生成使用。

- 明确主题、地域、期间和数据覆盖边界。
- 依次整理行业规模与增长、细分结构、核心参与者、业务模式、关键趋势、驱动因素和风险。
- 市场规模、增长率、公司排名和预测必须带来源与期间；历史值和预测值不得混用。
- 多条新闻或研报重复同一事件时按事件去重，并区分原始事实与机构观点。
- 没有充分数据时输出缺口，不使用通用行业常识填补。
