# 估值语境分析方法

- PE、PB、EV/EBITDA 等指标先核对分母期间、是否亏损、币种和企业价值口径。
- 相对估值只在业务模式与期间可比时使用，报告中位数、分位数和样本范围。
- PB 应与 ROE、资产质量结合；PE 应与盈利增长和一次性损益结合。
- DCF、DDM 或 SOTP 仅在现金流、资本成本、分部和预测假设齐全时作为可计算候选。
- 结论限于“估值水平和口径差异”，不生成目标价、评级或买卖建议。
