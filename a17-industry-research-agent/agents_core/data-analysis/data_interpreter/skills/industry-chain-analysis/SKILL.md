# 产业链解读方法

围绕输入数据中的产品、业务分类、客户供应商、收入占比、利润占比和毛利率构建产业链事实图谱。

- 先识别链条层级与节点，再把公司映射到有直接证据的节点；不凭公司名称猜测归属。
- 比较收入占比、利润占比和毛利率，描述价值分配，不把高毛利直接等同于长期壁垒。
- 关键节点需同时说明稀缺性证据、替代性证据和上下游影响；证据不足时降置信度。
- 供需、价格、政策或技术事件必须通过期间相符的行业、宏观、新闻或研报记录交叉验证。
- 区分事实、趋势、解释假设和风险，不输出买卖或估值结论。
