# 竞争格局分析方法

只基于输入数据集构建同行比较，不创建演示文稿，不自行扩展竞争对手集合。

- 先校验公司、证券代码、指标定义、币种、单位和期间；口径不一致的数据不得直接排名。
- 优先比较规模、增长、盈利能力、市场份额、业务结构和资本效率。
- “龙头”必须有明确选择依据，例如市场份额、收入、市值或行业排名，并说明依据的局限。
- 同一指标至少两个来源时做一致性检查；来源冲突必须并列展示，不擅自取舍。
- 竞争优势只可表述为由数据支持的相对差异；机制和因果若无证据，应标为待验证假设。
