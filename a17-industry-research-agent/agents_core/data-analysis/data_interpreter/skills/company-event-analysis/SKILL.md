# 公司事件解读方法

只基于输入中的公告、新闻和事件记录建立“主体—事件—日期—状态—影响对象”知识事实。

- 合并同一事件的重复报道，保留公告等一手来源与后续进展。
- 区分计划、董事会通过、股东大会通过、实施中、完成或终止，不能把意向当成完成事实。
- 金额、比例、价格、期限和交易对手必须逐项引用证据；缺失时不估算。
- 事件影响只描述股本、控制权、现金流或经营范围等可验证变化，不生成交易信号。
