# 量化统计验证方法

方法复杂度必须与样本量匹配；样本不足时使用描述性统计，不强行运行高级模型。

- 横截面异常优先使用中位数与 MAD；样本少于 5 个时不做离群判定。
- 趋势至少需要两个可比期间；若指标本身为同比或环比，可作为单条方向信号，但不得冒充完整时间序列。
- 相关性不代表因果；因果、协整、平稳性或波动率模型只有在样本长度和频率满足时才可提出。
- 多重检验、数据缺失、幸存者偏差、重复记录和口径变化均应进入限制说明。
- 每个统计结论记录方法、阈值、样本数、期间和 evidence_record_ids，确保可复算。
