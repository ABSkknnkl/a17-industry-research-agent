# 变量敏感性与盈利弹性测算方法

只基于输入中的财务报表、成本构成比例与主营数据建立客观测算模型，不猜测未经证实的非线性成本曲线。

- **确定关键敏感性变量**：
  - 上游成本侧：核心原材料、能源或运费成本占总营业成本的比例，测算成本变动 $\pm 5\% \sim 10\%$ 对毛利率的拉动或挤压；
  - 下游售价侧：终端产品出厂均价（ASP）变动 $\pm 3\% \sim 5\%$ 对净利润总额的弹性系数；
  - 需求销量侧：行业渗透率或下游出货量增速偏离基准情景时的经营杠杆放大倍数。
- **双变量敏感性矩阵测算**：
  - 建立“售价变动（横轴）× 原材料成本变动（纵轴）”的双向情景矩阵，计算样本企业的盈利波动区间；
  - 标出盈亏平衡点（Breakeven Point）对应的最低产品售价与最高容忍成本线。
- **抗风险韧性对比**：对比行业内不同梯队企业的毛利缓冲厚度（Buffer），识别对成本波动更具防御力的高护城河龙头。
- 测算所依据的基准营业收入、成本拆解比例与毛利数据必须全部来自底层真实的财务证据 ID。
