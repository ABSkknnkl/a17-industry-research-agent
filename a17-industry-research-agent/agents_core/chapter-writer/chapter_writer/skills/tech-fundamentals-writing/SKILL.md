# 科技赛道成长与实绩证伪写作

- **概念与实绩对照**：在阐述行业技术远景与驱动力时，必须显式对比概念预期与企业当期可验证的财务表现（营收规模、毛利率及主营业务纯度）。
- **杜绝线性外推**：严禁仅依据前瞻概念将远期潜在市场空间（TAM）线性折现为短期业绩；商业化进展必须基于已落地订单、量产批次或披露合作。
- **造血能力与研发质量论证**：论述龙头企业竞争力时，客观呈现研发费用资本化比例、经营活动现金流对资本开支的覆盖能力。
- **泡沫与分化警示**：对估值脱离行业基本面中枢过大的细分标的，客观陈述其估值倍数与业绩兑现风险，提供冷静客观的投行研判。
