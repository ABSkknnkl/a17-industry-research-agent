# 前端使用说明

## 启动

按 [项目部署说明](../SETUP.md) 启动后端，再在 `frontend/` 执行 `npm run dev`，访问 <http://localhost:5173>。开发代理默认访问 `http://localhost:8000`；需要更改时，在 `frontend/.env.local` 设置 `VITE_PROXY_TARGET`。不要把只含主机和端口的地址填入 `VITE_API_BASE_URL` 而遗漏 `/api/v1`。

## 操作流程

1. 在首页输入研究主题，选择市场、范围和需要人工审核的阶段。
2. 在任务列表或工作台查看进度；逐阶段核对数据、来源、图表和文字。
3. 使用审核操作通过、修改或重跑；运行失败、证据不足或质量阻塞时先处理告警。
4. 在报告页面查看实际可用的 Markdown、HTML 和 PDF。直接编辑融合报告后，旧 PDF 和质检结论作废；完整视图可先预览更新后的 Markdown/HTML，重新融合并质检后才可定稿并生成新 PDF。重新融合后请重新核对直接编辑的内容。

界面设置可以保存模型及问财配置；不保证所有外部服务可用。当前后端没有统一身份认证，默认服务及设置接口不应直接暴露到公网或不受信任网络。

验证命令和代码位置见 [前端 README](README.md)；当前实现和最近一次离线验证见 [当前版本说明](../docs/当前版本说明.md)。
