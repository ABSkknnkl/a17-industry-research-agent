## 3. T1 A1 自查、补数与放行

### 首轮自查

- **市场数据。** 核对 2021—2025 销量、渗透率和出口量的实际期间、地区、统计对象、来源和单位。汽车总量与乘用车、零售与批发分别列序列。渗透率只有在年度来源直接给出，或有同范围同年度的新能源销量和对应汽车销量时才可作为年度结果。累计序列取有效年度合计，月度率禁止直接取 12 月值或求简单平均。
- **企业财务。** 对比亚迪、长安汽车、赛力斯核对 3 年 × 3 指标的 27 格，逐格记录有效、缺失或不可比。经营现金流使用经营活动产生的现金流量净额。整车分部仅用已披露的该分部指标；集团营收、集团毛利率和集团经营现金流各按合并口径标注。宁德时代、亿纬锂能和整车样本分组审核，研发投入、研发费用和按同口径复算的研发费用率各自标记。
- **产业链。** 每条拟写的供需或合作关系记录双方、关系类型、披露日期及原文定位。链条环节和实际经营关系分别核验。同在某环节的企业只能证明环节归属。

### 先判缺口原因，再选处理方式

| 原始响应 → A1 的表现 | 处理 |
|---|---|
| 原始响应已经有目标值，A1 丢值或把月度、单位、范围读错 | 留原始响应样本，离线重放 `DataFusion.fuse`。确认触发条件后走 T4，优先修读错的规则。 |
| 当前响应只有相近口径 | 精确补采目标口径。已有相近数据单列为补充观察，目标格保持缺口。例，2025 年 12 月国内零售渗透率只回答当月观察。 |
| 原始响应成功，但目标记录确实缺失 | 按 `requirement_id` 定向查询公司或市场、指标全称、期间、范围、币种及单位，优先补会改变核心结论的单元。 |
| 同口径多个来源值冲突 | 查来源版本、公告日期、原表与更正记录，走既有更正与冲突逻辑。未能判定时隔离该格，标明影响的表、图和结论。 |
| 补采结果为空、超时、限流或鉴权失败 | 结合请求与结果日志区分空响应、调用失败和无合格记录。工具故障登记阻塞，缺数据要有成功查询或可核查的披露证据支撑。 |

## 4. T2 A2 分析与修订

1. **用生产入口重算。** 走 `FiveAgentsAdapter.run_data_interpreter`，确认从本次 `run_id` 读取已放行的 `dataset.json`，并使用冻结题面、市场、币种和指标要求。完整保存 `interpretation_report.json`，登记 A1 输入哈希和 A2 报告 ID。
2. **先核对可计算结论。** 核对覆盖矩阵、`evidence_index`、`analysis_facts`、`semantic_checks`、表格和主要结论。同比核对同口径的基期与当期，基期为零或为负时采用项目既有处理规则。毛利率差用百分点。集团与分部各用自己的范围。分组研发费用率检查同组同年度的分子分母及完整样本，复算“组内费用合计 ÷ 同一组营收合计”。链路验证要区分已披露关系、假设和证据缺口。
3. **对每道题审查文字。** 对主结论记录“结论 → 对比基准 → 证据 ID → 可支持的解释”。每个核心数字至少交代比较对象、期间与业务含义。数据只支持差异时，写清差异来自哪个指标或样本；能支持原因时再补解释和出处。示例句式“同口径下，[主体]的[指标]较[基准]变动[数值]，主要差异集中于[可复算的项目]。[证据 ID]”。若没有成因证据，说明“现有材料无法拆分成因”，避免用宏观套话补位。
4. **定位再修订。** A1 有证据、A2 未纳入时，检查需求映射、样本分组、过滤和索引生成。事实有据但指标公式、期间或单位错误时，用同一输入离线重跑确定性分析与事实构建，修对应路径。结构化事实正确、摘要或洞察错误时，优先在生成或对齐环节修该类结论，联动摘要、洞察、表格和告警；完整保留原稿与修订依据。有依据才能细化原因，缺上游数据就回到 T1 的缺口分类。
